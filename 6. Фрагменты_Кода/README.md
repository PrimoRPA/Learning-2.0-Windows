# 6. Фрагменты кода

Готовые фрагменты кода (сниппеты) для часто повторяющихся конструкций — вставляются в проект без необходимости писать их с нуля. Материалы продублированы на русском (`ru`) и английском (`eng`) языках.

> 📖 Общая навигация по репозиторию — в [README главной страницы](../README.md).

## 💡 Как использовать

1. Скопируйте нужный файл `.ltw` с подходящим сниппетом в папку с уже созданным проектом
2. Откройте проект в Primo RPA Studio
3. Откройте скопированный сниппет в Primo RPA Studio из дерева проекта (вкладка "Проект")
