# File_Sorter

Сортировщик файлов: раскладывает файлы из папки `Data/Input` по подпапкам `Data/Sorted` в зависимости от типа (PDF, Word, Excel, Images, Archives, Other).

Самый простой пример раздела: работа с файловой системой, цикл и обработка ошибок без внешних приложений. Подходит для знакомства с Primo RPA.

## Что демонстрирует

| Элемент | Зачем он здесь |
| :--- | :--- |
| **Множественное присвоение** | задаёт все настройки процесса одним шагом |
| **Существует файл или папка** + **If-Else** + **Исключение** | проверяет входную папку и останавливает процесс с понятным сообщением |
| **Поиск файлов** | собирает список файлов из папки |
| **Цикл ForEach** | обрабатывает файлы по одному |
| **Try-Catch** | ошибка на одном файле не останавливает остальные |
| **Ссылка на процесс** | вызывает подпроцесс `SortFile` и получает от него категорию |
| **Создать папку**, **Переместить файл** | создают папку категории и переносят в неё файл |
| **Запись в журнал** | фиксирует ход работы |

## Структура

| Файл / папка | Назначение |
| :--- | :--- |
| `Main.ltw` | главный процесс: проверка папки, поиск файлов, цикл |
| `Components/SortFile.ltw` | определяет категорию по расширению и перемещает файл |
| `Data/Input/` | тестовые файлы разных типов |

## Как запустить

1. Откройте `project.ltp` в Primo RPA Studio.
2. Запустите `Main.ltw` (`F5`).

**Ожидаемый результат:** в `Data/Sorted` появятся папки `PDF` (1 файл), `Word` (1), `Excel` (2: `budget.xlsx`, `data.csv`), `Images` (1), `Archives` (1) и `Other` (2: `notes.txt`, `unknown.xyz`). Входная папка опустеет, поэтому для повторного запуска верните файлы в `Data/Input`.

## Как адаптировать

- Другие папки: измените значения в элементе «Настройки» в начале `Main.ltw`.
- Новый тип файлов: добавьте расширение в выражение элемента «Определить категорию» в `SortFile.ltw`.
