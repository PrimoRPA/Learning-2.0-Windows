# Excel_Validator

Проверка данных в Excel: проверяет в таблице контактов формат ИНН, e-mail и телефона, записывает статус рядом с каждой строкой и подсвечивает строки с ошибками. Результат сохраняется в новый файл, исходный не меняется.

## Что демонстрирует

| Элемент | Зачем он здесь |
| :--- | :--- |
| **Приложение Excel** + **Чтение диапазона** | загружает контакты в `DataTable` |
| **Цикл ForEach для DataTable** | проверяет каждую строку |
| **Ссылка на процесс** | вызывает подпроцесс `ValidateRow` и получает от него текст ошибок |
| **Удалить пробелы**, **Длина строки** | готовят и проверяют ИНН |
| **Регулярное выражение (IsMatch)** | проверяет формат ИНН, e-mail и телефона |
| **If-Else** | выбирает, что записать: «OK» или текст ошибки |
| **Ввод в ячейку**, **Изменение ячейки** | пишут статус и подсвечивают строку с ошибкой |
| **Сохранить документ** | сохраняет результат под новым именем |

## Правила проверки

| Поле | Правило |
| :--- | :--- |
| ИНН | только цифры, длина 10 или 12 |
| Email | `текст@домен.зона` |
| Телефон | `+7` и 10 цифр |

## Структура

| Файл / папка | Назначение |
| :--- | :--- |
| `Main.ltw` | чтение таблицы, цикл, запись статусов, сохранение |
| `Components/ValidateRow.ltw` | проверка одной строки |
| `Data/Contacts.xlsx` | тестовые данные (лист `Contacts`: Организация, ИНН, Email, Телефон) |

## Как запустить

1. Откройте `project.ltp` в Primo RPA Studio.
2. Запустите `Main.ltw` (`F5`).

**Ожидаемый результат:** появится файл `Data/Contacts_checked.xlsx` со столбцом «Статус проверки» (E). По тестовым данным:

| Организация | Статус |
| :--- | :--- |
| ООО «Ромашка» | OK |
| АО «Вектор» | ИНН: нужно 10 или 12 цифр |
| ИП Смирнов | Email: неверный формат |
| ООО «Орбита» | ошибки ИНН и телефона |
| ООО «Заря» | OK |
| ЗАО «Север» | Телефон: нужен формат +7XXXXXXXXXX |
| ООО «Луч» | OK |

Строки с ошибками (4 из 7) подсвечены. Адрес `луч@mail.ru` проходит проверку: правило допускает любые символы, кроме `@` и пробела. Чтобы запретить кириллицу, измените шаблон в `ValidateRow.ltw`.
