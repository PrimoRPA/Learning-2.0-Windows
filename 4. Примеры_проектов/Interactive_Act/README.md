# Interactive_Act

Тестовый процесс для демонстрации работы элементов Interactive Activities.

Элементы продемонстрированные в проекте:
Progress Bar
Display Message

Проект получает курс валют за определённую дату, сохраняет эти данные в таблицу и отправляет почтой.

Входные данные: Текст писем из почты

### Process.ltw

ltw, в котором собраны основные элементы для обработки входных данных.

### AddToExel.ltw

ltw, открывающий .xlsx файл и добавляет небходимые данные в табицу

### OpenCBWebsite.ltw

ltw, запускающий браузер с необходимой страницой курса валют Центрального банка.
