# Mail_Attachments

Обработка вложений из почты: читает непрочитанные письма из папки Outlook, сохраняет вложения на диск, переносит обработанные письма в папку «Обработано» и распаковывает ZIP-архивы.

## Что демонстрирует

| Элемент | Зачем он здесь |
| :--- | :--- |
| **Приложение Outlook** + **Чтение почты** | получает непрочитанные письма из выбранной папки |
| **Цикл ForEach** (двойной) + **If-Else** | перебирает письма, а внутри них вложения |
| **Сохранить вложение** | записывает вложения в `Data/Attachments` |
| **Переместить в папку** | убирает обработанное письмо из «Входящих», чтобы не обработать его дважды |
| **Поиск файлов** | находит сохранённые ZIP-архивы |
| **Ссылка на процесс** + **Извлечь архив** | распаковывает каждый архив в отдельную подпапку |
| **Try-Catch** | ошибка в одном архиве не останавливает остальные |

Контейнер Outlook закрывается до работы с файлами: почта и файловые операции выполняются отдельно.

## Структура

| Файл / папка | Назначение |
| :--- | :--- |
| `Main.ltw` | чтение почты, сохранение вложений, цикл по архивам |
| `Components/UnpackArchive.ltw` | распаковка одного архива |
| `Data/` | сюда сохраняются вложения (`Attachments`) и распаковки (`Unpacked`) |

## Требования и настройка

- Установленный и настроенный Microsoft Outlook.
- Программа 7-Zip (путь к `7z.dll` задан в `UnpackArchive.ltw`: `C:\Program Files\7-Zip\7z.dll`).
- В элементе «Настройки» в начале `Main.ltw` замените в путях `\\Outlook\...` слово `Outlook` на название своего почтового ящика в Outlook. Папку «Обработано» создайте заранее.

## Как запустить

1. Положите в «Входящие» несколько непрочитанных писем с вложениями (хотя бы одно с ZIP-архивом).
2. Откройте `project.ltp` в Primo RPA Studio и запустите `Main.ltw` (`F5`).

**Ожидаемый результат:** вложения сохранены в `Data/Attachments`, письма перенесены в «Обработано», ZIP-архивы распакованы в `Data/Unpacked`.
