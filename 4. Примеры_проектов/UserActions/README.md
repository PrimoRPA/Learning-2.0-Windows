# UserAction

Проект демонстрирует возможности платформы Primo RPA взаимодействовать с пользователем во время работы программного робота.

 В проекте представлена:
* Работа с формами пользовательского ввода
* Работа с диалоговыми окнами
* Работа с активностями пакета Primo.Interactive.Activities
* Работа с событиями, отслеживающими запуск, остановку и изменения в приложении Калькулятор, PowerPoint, Google Chrome
* Составление файла, отражающего произошедшие в системе действия
