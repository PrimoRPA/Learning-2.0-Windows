# PDF_Package

Сборка PDF-пакета: берёт все PDF из папки, считает страницы в каждом, объединяет их в один файл, ставит водяной знак «КОПИЯ» и записывает текстовый отчёт.

## Что демонстрирует

| Элемент | Зачем он здесь |
| :--- | :--- |
| **Поиск файлов** | собирает список PDF по маске `*.pdf` |
| **If-Else** + **Исключение** | останавливает процесс, если для объединения мало файлов |
| **Цикл ForEach** | обходит файлы |
| **Кол-во страниц** | считает страницы в каждом PDF |
| **Запись в файл**, **Добавить строку** | создают отчёт и дописывают в него строки |
| **Ссылка на процесс** | вызывает подпроцесс `MergePdf` |
| **Объединение документов** | склеивает два PDF за раз; подпроцесс повторяет это для любого количества файлов |
| **Удалить файл или папку** | убирает промежуточные результаты |
| **Добавление водяного знака** | ставит знак на все страницы итогового файла |

## Структура

| Файл / папка | Назначение |
| :--- | :--- |
| `Main.ltw` | поиск файлов, отчёт, вызов объединения, водяной знак |
| `Components/MergePdf.ltw` | объединение списка PDF попарно |
| `Data/Input/` | три тестовых PDF (`contract.pdf` — 2 стр., `invoice.pdf` — 1 стр., `act.pdf` — 3 стр.) |

## Как запустить

1. Откройте `project.ltp` в Primo RPA Studio.
2. Запустите `Main.ltw` (`F5`).

**Ожидаемый результат** в `Data/Output`: `Package.pdf` (6 страниц), `Package_Copy.pdf` (то же с водяным знаком) и `Report.txt` со страницами по каждому файлу и общей суммой.

Размер водяного знака задаётся в элементе «Водяной знак» (свойство «Размер шрифта»); при необходимости подберите его под свои документы.
