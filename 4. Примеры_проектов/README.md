# 4. Примеры проектов

Готовые тематические роботы, показывающие, как элементы из [каталога](../README.md#-структура-репозитория) сочетаются в цельном рабочем процессе. В отличие от раздела 1-3, здесь не один элемент = один пример, а завершённый сценарий автоматизации.

> 📖 Общая навигация по репозиторию — в [README главной страницы](../README.md).

## 🚀 Как запустить

1. Откройте нужную папку проекта в Primo RPA Studio (файл `.ltp`)
2. Проверьте пути к входным файлам — некоторые примеры используют файлы из [Дополнительные материалы](../Дополнительные%20материалы)
3. Запустите процесс через `F5`
