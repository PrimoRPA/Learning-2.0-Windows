# PrimoAIServer

Тестовый процесс для демонстрации работы Primo RPA AI Server.

Проект TestAIWithClass получает документы из Input_Folder и направляет в Primo AI Server для классификации по типам. После классификации отправляет в Primo AI Server для получения атрибутов документов. Полученные атрибуты сохраняются в Excel и Json-файлы.

Проект TestAIWithoutClass получает документы из папок passport, snils, torg12, которые расположены внутри папки Input_Folder. Полученные документы направляет в Primo AI Server для получения атрибутов документов. Полученные атрибуты сохраняются в Excel и Json-файлы.
