# Document_Generator

Генератор документов: читает список сотрудников из Excel, для каждого создаёт приказ в Word по шаблону и сохраняет его копию в PDF.

Типичная задача для бизнеса: массовое формирование однотипных документов (приказы, письма, акты, справки).

## Что демонстрирует

| Элемент | Зачем он здесь |
| :--- | :--- |
| **Приложение Excel** + **Чтение диапазона** | загружает таблицу сотрудников в `DataTable` |
| **Цикл ForEach для DataTable** | создаёт один документ на каждую строку |
| **Ссылка на процесс** | вызывает подпроцесс `CreateDocument` с данными строки |
| **Копировать файл** | делает копию шаблона, сам шаблон не меняется |
| **Документ Word** + **Заменить текст** | подставляет данные вместо меток `{Номер}`, `{ФИО}`, `{Должность}`, `{Дата}` |
| **Сохранить документ**, **Экспортировать документ** | сохраняют результат в `.docx` и `.pdf` |
| **Try-Catch** | ошибка на одном сотруднике не останавливает остальных |

Excel закрывается сразу после чтения данных, а Word открывается позже отдельным контейнером: контейнеры разных приложений нельзя вкладывать друг в друга.

## Структура

| Файл / папка | Назначение |
| :--- | :--- |
| `Main.ltw` | чтение Excel и цикл по сотрудникам |
| `Components/CreateDocument.ltw` | создание одного документа из шаблона |
| `Data/Employees.xlsx` | список сотрудников (лист `Employees`: Номер, ФИО, Должность, Дата приема) |
| `Data/Template.docx` | шаблон приказа с метками |

## Требования

На машине должны быть установлены Microsoft Excel и Microsoft Word.

## Как запустить

1. Откройте `project.ltp` в Primo RPA Studio.
2. Запустите `Main.ltw` (`F5`).

**Ожидаемый результат:** в `Data/Output` появятся 4 документа Word (`Order_001.docx` … `Order_004.docx`) и 4 PDF с теми же именами.

## Как адаптировать

Чтобы добавить поле, добавьте столбец в Excel, метку в шаблон Word, аргумент в `CreateDocument.ltw` и ещё один элемент «Заменить текст».
