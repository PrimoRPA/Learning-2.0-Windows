# Web_Helpdesk_Login

Вход в систему Helpdesk: робот вводит логин и пароль, нажимает «Войти», читает приветствие и выходит из системы.

## Сайт

| Файл | Что это |
| :--- | :--- |
| `Site/helpdesk.html` | Helpdesk «Опора»: вход в систему (логин `operator`, пароль `demo123`), форма новой заявки и таблица заявок |

## Что демонстрирует

| Элемент | Элемент страницы | Зачем он здесь |
| :--- | :--- | :--- |
| **Открыть браузер** | — | открывает сайт, контейнер для остальных шагов |
| **Ввод текста** | `INPUT#login-user` | вводит логин |
| **Ввод текста** | `INPUT#login-password` | вводит пароль |
| **Клик мышью** | `BUTTON#login-button` | нажимает «Войти» |
| **Получить текст** | `SPAN#current-user`, `H2#welcome-title` | читает имя пользователя и приветствие |
| **Клик мышью** | `BUTTON#logout-button` | выходит из системы |
| **Закрыть браузер** | — | закрывает браузер |

Все шаги выполняются внутри контейнера «Открыть браузер». Проект линейный: без условий и циклов.

## Структура

| Файл / папка | Назначение |
| :--- | :--- |
| `Main.ltw` | весь сценарий |
| `Site/helpdesk.html` | учебный сайт |

## Требования и запуск

- Primo RPA Studio и расширение Primo для Google Chrome (как в остальных примерах раздела «Браузер»).
- Сайт лежит в папке `Site` и открывается как локальный файл. Для страниц-файлов Chrome по умолчанию не разрешает расширениям доступ: в `chrome://extensions` откройте расширение Primo и включите «Разрешить доступ к URL-адресам файлов».
- Если нужно, разместите файл из `Site` на любом веб-сервере и замените значение переменной `strSiteUrl` в элементе «Настройки» на его адрес.

1. Откройте `project.ltp` в Primo RPA Studio.
2. Запустите `Main.ltw` (`F5`).

Сайт учебный, данные на нём вымышленные. Состояние сайта (например, номер заказа) сбрасывается при каждой загрузке страницы.

## Ожидаемый результат

В журнале появятся записи:

- `Вход выполнен. Пользователь: operator. Добро пожаловать, operator!`

Пароль в проекте учебный и виден в коде. В реальных проектах храните пароли в Credential Manager или в учётных данных Оркестратора.

## Если элемент не нашёлся

Элементы страницы заданы по атрибуту `id`, который есть в файле из папки `Site`. Если Studio не находит элемент (например, вы изменили страницу), снова укажите его: откройте нужный шаг, нажмите на «волшебную палочку» и выберите элемент на странице.
