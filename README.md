<a id="glossary"></a>
## 📘 Мини-глоссарий

Если вы новичок в Primo RPA, эти термины встретятся в репозитории чаще всего:

| Термин | Что это |
| :--- | :--- |
| **Primo RPA Studio** | Программа-редактор, в которой собираются роботы (аналог IDE для автоматизации) |
| **Робот / процесс** | Готовый сценарий автоматизации, собранный из элементов Studio |
| **Элемент / активность** | Один «кубик» логики в Studio — например, «Открыть браузер» или «Чтение диапазона» |
| **.ltw** | Файл процесса Primo RPA — по сути один экран логики робота, открывается в Studio |
| **.ltp / .ltr** | Файлы проекта и релиза Primo RPA — открывается через них весь проект целиком |
| **Режим разработки** | Способ описания логики: последовательность, диаграмма или код (см. таблицу ниже) |
| **Оркестратор** | Серверная часть Primo RPA — управляет роботами, очередями задач и логами |
| **Фреймворк / шаблон** | Заготовка проекта с уже настроенной структурой (обработка ошибок, логирование и т.д.) |

## ⚡ Быстрый старт

### 🟢 Скачать без Git — самый простой способ

1. В верхней части страницы репозитория на GitHub нажмите зелёную кнопку **`<> Code`**
2. Выберите **Download ZIP**
3. Распакуйте архив в удобную папку, например `C:\Primo RPA\Learning-2.0-Windows`
4. Откройте **Primo RPA Studio** → **Открыть проект** → выберите нужную папку с примером → откройте файл `.ltp` (или сразу `.ltw`, если хотите посмотреть один элемент)
5. Нажмите `F5` или кнопку **Старт**, чтобы запустить пример

> Этого достаточно, чтобы посмотреть и запустить любой пример. Git не нужен, если вы не планируете регулярно обновлять репозиторий.

### 🔧 Через Git — если планируете обновлять репозиторий

```bash
git clone https://github.com/PrimoRPA/Learning-2.0-Windows.git
```
Дальше — так же, как в шаге 4 выше: открываете нужный `.ltp`/`.ltw` в Studio.

## 🎯 Какой режим выбрать

Все примеры элементов продублированы в трёх режимах — это разные способы писать логику одного и того же робота.

| Режим | Как выглядит | Когда использовать |
| :--- | :--- | :--- |
| 🟦 **1. Последовательность** | Простой список шагов сверху вниз | Линейные сценарии без сложных условий: заполнить форму, обработать файл, зайти на сайт. **Рекомендуется новичкам.** |
| 🟨 **2. Диаграмма** | Блок-схема со стрелками и ветвлениями | Много условий и циклов, сложная бизнес-логика, несколько взаимосвязанных процессов |
| 🟩 **3. Чистый код** | Код на C# | Интеграции через API, работа с JSON/RegEx, сложные вычисления, минимум работы с интерфейсом программ |

Каждый режим содержит **одинаковый набор категорий элементов** (Excel, Word, Браузер, Данные и т.д.) — только реализованных по-своему. Поэтому если непонятно, что делает элемент — посмотрите тот же пример в режиме «Последовательность», там логика читается проще всего.

<a id="find-element"></a>
## 🔍 Как найти нужный элемент

1. Откройте раздел **[📂 Каталог элементов по режимам](#catalog)** ниже
2. Раскройте нужный режим (клик по строке `▶ 1. Режим - Последовательность`)
3. Раскройте категорию, к которой относится элемент (например, «Приложение Excel»)
4. В таблице найдите название элемента и прочитайте описание — там же указано, что делает пример
5. Перейдите по ссылке 📁 у категории — она ведёт прямо в папку с файлами `.ltw` на GitHub

## 📋 Сценарии использования

Примеры покрывают реальные бизнес-кейсы:

| Сценарий | Используемые категории |
| :--- | :--- |
| 🏦 Банки/Финансы | Выгрузка из 1С → Обработка Excel → Отправка по почте |
| 🛒 Ритейл | Парсинг прайсов с сайтов → Загрузка в Google Sheets |
| 🏛️ Госсектор | Работа с PDF-отчётами → Электронная подпись → Отправка |
| 🏭 Производство | Чтение данных SQL → Отправка в RabbitMQ/Kafka → UI-уведомления |
| 📱 AI-обработка документов | Классификация документов → Извлечение атрибутов через Primo AI Server |
