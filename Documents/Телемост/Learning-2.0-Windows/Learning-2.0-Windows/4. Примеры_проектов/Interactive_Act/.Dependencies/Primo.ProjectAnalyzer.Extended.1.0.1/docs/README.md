# About
Primo.ProjectAnalyzer.Extended package is designed for use in Primo RPA Studio and is intended to expand the functionality of the studio analyzer. In particular, the package contains an extensive set of additional rules for analyzing algorithms and structures of projects and processes.

# How to Use
- In Primo RPA studio, create a new project or upload an existing one for analysis and execution.
- Install this package via the menu ".Dependencies → Manage Dependencies". 
- Open the analyzer settings panel using the menu "Home → Analysis → Analyse settings" in the "Ribbon" menu style or "Analysis → Analyse settings" in the "Bar" menu style.
- In the window that opens you can see a table with all rules, including new ones. 
- Add these rules to the analyzer by checking the corresponding text boxes on the left in the rule lines.
- By clicking the menu items "Analyze process" and "Analyze project" (path "Home → Analysis" or "Analyze"), the "Analysis" window will open, if it is not already open, the studio will analyze the process or project, the results will appear in the table of the "Analysis" panel.

# Key Features

- Expands analizer's functionality
- For using in Primo RPA studio
- Supports .NET Framework 4.6.1+
