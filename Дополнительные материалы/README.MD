# Дополнительные материалы

Вспомогательные файлы (тестовые данные, документы, изображения), которые используются примерами из разделов [1–3](../README.md#-структура-репозитория): входные Excel/PDF-файлы, тестовые архивы, изображения для OCR, HTML-формы и т.д.

> ⚠️ Эта папка должна лежать рядом с папками режимов (как в исходной структуре репозитория) — многие примеры ссылаются на файлы отсюда по относительному пути.

> 📖 Общая навигация по репозиторию — в [README главной страницы](../README.md).
