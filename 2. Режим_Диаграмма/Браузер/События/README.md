| Подпапка | Что делает и когда нужна |
| :--- | :--- |
| **«Клик элемента»** | Запускает часть процесса не по расписанию, а в момент, когда пользователь кликнул по определённому элементу на странице. Нужен для сценариев «человек + робот», где робот реагирует на действия пользователя в браузере, а не работает полностью самостоятельно. |
