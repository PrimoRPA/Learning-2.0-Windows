# Kafka

Элементы для обмена сообщениями через брокер **Apache Kafka**.

## Что такое Kafka

Kafka — высоконагруженный брокер сообщений для потоковой обработки данных. В отличие от ActiveMQ, Kafka хранит все сообщения в топике длительное время и позволяет читать их заново. Используется там, где важны большие объёмы данных, скорость и возможность воспроизвести поток событий с любого момента. Популярен в аналитических и event-driven архитектурах.

> Перед использованием нужно настроить подключение к серверу Kafka: адрес bootstrap-сервера, имя топика и, при необходимости, параметры аутентификации (SASL/SSL).

## 📋 Элементы

| Элемент | Что делает и когда нужен |
| :--- | :--- |
| **Отправить сообщение** | Публикует сообщение в топик Kafka. Нужен, когда Primo RPA должен передать событие или данные в поток — например, результат обработки документа, который другие сервисы должны получить и обработать по-своему. |
| **Получить сообщения** | Считывает сообщения из топика Kafka в массив. Нужен, когда Primo RPA должен подхватить события из потока — например, реагировать на новые транзакции, поступающие из банковской системы через Kafka. |
