# Очереди сообщений

Элементы для обмена сообщениями через внешние брокеры. Используются для интеграции Primo RPA с другими системами через событийную шину — когда роботу нужно опубликовать событие или подписаться на входящие сообщения.

## Чем отличается от очередей Оркестратора

| | Очереди Оркестратора | Очереди сообщений (этот раздел) |
| :--- | :--- | :--- |
| **Где хранятся** | Внутри Primo RPA Orchestrator | Во внешнем брокере (ActiveMQ, Kafka) |
| **Кто читает** | Только роботы Primo RPA | Любые системы, подключённые к брокеру |
| **Когда использовать** | Передача заданий между роботами | Интеграция с внешними системами через шину |
