# Диаграмма


| №  | Название активности | Краткое описание процесса |
|----|--------------------------------------|----------------------------------------------------|
| 1  | Диаграмма							| Активность является контейнером для диаграммы, которую можно разместить как в последовательности, так и в другой диаграмме. |
| 2  | Последовательность                 	| Активность представляет собой контейнер для любых других активностей. Может использоваться для логической группировки активностей.  |
