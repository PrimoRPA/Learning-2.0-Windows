# Работа с UI

Элементы для взаимодействия с элементами интерфейса приложений и браузера: клики, ввод текста, ожидание элементов, чтение значений.

> В примерах используется переключатель между браузером (Chrome) и тестовым приложением MyCRM — одни и те же элементы работают в обоих.

## 📋 Элементы

| Элемент | Что делает и когда нужен |
| :--- | :--- |
| **Якорь** | Привязывает поиск целевого элемента к другому, стабильному элементу-ориентиру. Нужен, когда целевой элемент сам по себе найти сложно, но рядом с ним всегда есть что-то постоянное — заголовок, метка. Делает сценарий устойчивее к изменениям интерфейса. |
| **Клик мышью** | Выполняет клик по указанному элементу интерфейса. Основной элемент для нажатия кнопок, выбора пунктов меню, активации полей. |
| **Клик текста мышью** | Кликает по элементу, найденному по его видимому тексту. Удобнее, чем искать по координатам — работает, даже если расположение элемента меняется. |
| **Ввод текста** | Вводит текст в поле интерфейса. Основной способ заполнять текстовые поля в приложениях и браузерах. |
| **Выбор значения** | Выбирает значение в выпадающем списке (select, combo box). Нужен, когда нужно установить конкретный пункт из списка. |
| **Выбрать элемент** | Устанавливает или снимает галочку в чекбоксе. |
| **Перетаскивание** | Перетаскивает один элемент к другому (drag-and-drop). Нужен для интерфейсов, где действия выполняются перетаскиванием. |
| **Получить текст** | Считывает видимый текст элемента интерфейса. Нужен, чтобы прочитать значение поля, статус, сообщение об ошибке или результат вычисления прямо с экрана. |
| **Получение списка** | Возвращает дочерние элементы контейнера (строки таблицы, пункты списка). Нужен, чтобы перебрать все элементы списка в цикле. |
| **Присутствие элемента** | Проверяет, виден ли элемент на экране, и возвращает True/False без ожидания и ошибки. Нужен перед условным действием — «если кнопка есть, нажать». |
| **Исчезновение элемента** | Ждёт, пока элемент пропадёт с экрана. Нужен для синхронизации с медленным приложением — например, дождаться закрытия спиннера загрузки. |
| **Фокус ввода** | Устанавливает фокус на поле без клика. Нужен, когда приложение ожидает фокуса перед вводом, но клик вызывает нежелательные побочные эффекты. |
| **Установить курсор мыши** | Перемещает курсор к элементу. Нужен для элементов, которые появляются только при наведении (hover-меню, подсказки). |
