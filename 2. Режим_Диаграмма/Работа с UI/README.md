# Работа с UI

## В примерах используется элемент "Заглушка". Переключатель в левом положении будет демонстрировать работу браузера, а в правом полжении будет использовать приложение


| №  | Название активности | Краткое описание процесса |
|----|--------------------------------------|----------------------------------------------------|
| 1  | Якорь								| Компонент предназначен для привязки действий к определённой области экрана или контейнеру приложения, что повышает точность поиска элементов и устойчивость сценария при изменениях интерфейса. |
| 2  | Выбрать элемент          			| Компонент предназначен установки или снятия галочки в чек-боксе. В примере осуществлен процесс установки галочки в чек-боксе в браузере или в тестовом приложении My CRM. |
| 3  | Присутствие элемента         		| Компонент предназначен для проверки наличия элемента управления на экране или в интерфейсе приложения с возвратом логического значения (истина/ложь) без ожидания или генерации ошибки. Так же с помощью этого компонента можно записать в переменные ссылки на элементы управления для дальнейшего использования. |
| 4  | Исчезновение элемента           		| Компонент предназначен для ожидания скрытия или удаления элемента из интерфейса (например, исчезновения кнопки), что позволяет синхронизировать выполнение сценария с состоянием приложения. В примере осуществлен процесс ожидания исчезновения элемента в браузере и тестовом приложении My CRM. |
| 5  | Клик мышью       					| Компонент предназначен для выполнения клика мышью (левой, правой, средней кнопкой, двойной клик или программный клик) по указанному элементу интерфейса или координатам экрана. В примере осуществлен процесс клика по элементу в браузере и тестовом приложении My CRM. |
| 6  | Клик текста мышью       				| Компонент предназначен для поиска текстовой строки в десктопном приложении или веб-странице и выполнения клика мышью по её расположению, что полезно при отсутствии доступа к элементам через стандартные селекторы. |
| 7  | Ввод текста     						| Компонент предназначен для ввода текстовых данных в активное поле ввода с использованием клавиатуры (эмуляция нажатий) или прямой вставки значения. В примере осуществлен процесс ввода текста в браузере и тестовом приложении My CRM. |
| 8  | Фокус ввода     						| Компонент предназначен для установки фокуса ввода на указанный элемент управления (поле ввода, текстовое окно), что необходимо перед выполнением операций ввода данных. В примере осуществлен процесс установки фокуса ввода в браузере и тестовом приложении My CRM. |
| 9  | Выбор значения     					| Компонент предназначен для выбора значения из выпадающего списка, комбобокса или элемента управления с предопределёнными вариантами (например, выбор из списка статусов или категорий). В примере осуществлен процесс выбора значения из выпадающего списка в браузере и тестовом приложении My CRM. |
| 10  | Получить текст     					| Компонент предназначен для извлечения текстового содержимого элемента интерфейса (заголовка, метки, поля) и сохранения его в переменную для последующей обработки или проверки. В примере осуществлен процесс получения текста из браузера или тестового приложения My CRM. |
| 11  | Получение списка     				| Компонент предназначен для извлечения всех доступных значений из элемента управления списком (ListBox, ComboBox, DropDownList) с сохранением в коллекцию или массив данных, а так же сохранением уже выбранного значения в отдельную переменную. В примере осуществлен процесс получения списка из браузера и тестового приложения My CRM. |
| 12  | Перетаскивание     					| Компонент предназначен для выполнения операции "перетащи и отпусти" (drag and drop) между координатами экрана для перемещения объектов или изменения их порядка. |
| 13  | Установить курсор мыши     			| Компонент предназначен для перемещения курсора мыши в указанную позицию экрана или к определённому элементу интерфейса без выполнения клика, что может использоваться для навигации или активации подсказок. |
