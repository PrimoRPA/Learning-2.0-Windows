# Оркестратор

Элементы для взаимодействия с **Primo RPA Orchestrator**: управление очередями обмена данными, запуск роботов и процессов, работа с общими ресурсами.

> ⚠️ Все элементы этого раздела работают только в **Primo RPA Studio Enterprise** с подключённым Оркестратором.

> 📖 Общая навигация — в [README главной страницы](../../README.md).
