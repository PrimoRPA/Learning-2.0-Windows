# Ресурсы

##Все элементы группы "Оркестратор" работают только в Primo RPA Studio Enterprise. Необходим подключенный оркестратор к студии.

| №  | Название активности | Краткое описание процесса |
|----|--------------------------------------|----------------------------------------------------|
| 1  | Заблокировать ресурс					| Элемент позволяет как блокировать, так и разблокировать ресурсы для других роботов, которые используют один ресурс. Это даёт возможность эффективно контролировать доступ к различным ресурсам в Оркестраторе. |
| 2  | Получить ресурс            			| Элемент позволяет получить ресурс (Asset) и его данные из Оркестратора по его названию. Ресурс Доступна работа с ресурсами разных типов данных: String, Integer, Floating, Boolean, DateTime и JObject. Полученный ресурс сохраняется роботом в переменной соответствующего типа данных, которую необходимо указывать в поле "Результат". |
| 3  | Получить учетные данные         		| С помощью этого элемента в Оркестраторе можно получить значение ресурса, который содержит учетные данные пользователя и имеет тип Credential. Поиск нужного ресурса происходит по его названию. |
| 4  | Установить ресурс         			| С помощью этого элемента в Оркестраторе можно изменить значение ресурса. Ресурс для изменения указывается в поле "Наименование". |
| 5  | Установить учетные данные         	| С помощью этого элемента в Оркестраторе можно изменить значение ресурса, который содержит учетные данные пользователя и имеет тип Credential. Ресурс для изменения указывается в поле "Наименование". |
