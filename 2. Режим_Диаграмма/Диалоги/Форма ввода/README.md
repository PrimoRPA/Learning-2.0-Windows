# Форма ввода


| №  | Название активности | Краткое описание процесса |
|----|--------------------------------------|----------------------------------------------------|
| 1  | Форма ввода							| Активность используется для отображения пользовательских форм ввода. Форму ввода необходимо создать в утилите "Редактор диалогов" раздела "Инструменты". Использование инструмента более подробно описано в документации https://docs.primo-rpa.ru/primo-rpa/primo-rpa-studio/tools/dialogs-editor. |
| 2  | Закрыть форму	                 	| Активность используется для закрытия ранее открытой формы ввода. |
