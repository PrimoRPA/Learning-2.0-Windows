# Диалоги


| №  | Название активности | Краткое описание процесса |
|----|--------------------------------------|----------------------------------------------------|
| 1  | To Do								| Компонент позволяет добавить заметку в любой точке кода робота, которая будет отображаться в студии на вкладке To Do. При двойном клике на заметку из вкладки To Do студия открывает тот фрагмент кода робота, где был установлен компонент. |
| 2  | Всплывающее сообщение                | Компонент, производящий отображение всплывающего уведомления (Toast Notification) с заданным сообщением. |
| 3  | Выбор файла                			| Компонент отображает диалог, для выбора файла или папки. Элемент можно применять для взаимодействия пользователя с роботом. |
| 4  | Диалог ввода                			| Компонент отображает диалог ввода, для взаимодействия пользователя с роботом. В примере осуществлен процесс вывода диалога, на котором можно выбрать один из пунктов. Информация из выбранного пункта сохраняется в переменной. |
| 5  | Добавить поля журнала                | Активность используется, для добавления дополнительных полей в журнал. В дальнейшем эти поля будут отображаться в консоли при использовании элемента "Записать в журнал", а также будут отображаться в журнале оркестратора.  |
| 6  | Запись в журнал                		| Активность используется для записи какой-либо информации (логов) в Консоль Primo RPA Studio при разработке процесса и в пользовательский журнал при запуске процесса из Оркестратора. |
| 7  | Звуковой сигнал                		| Активность воспроизводит звуковой сигнал заданной протяженности и частоты указанных в свойствах активности. |
| 8  | Комментарий                			| Активность предназначена для создания пометок в любой точке кода робота, например для разъяснения каких-либо тонкостей разработки или разных пометок. |
| 9  | Окно сообщения                		| Активность отображает окно с сообщением, которое можно использовать для взаимодействия пользователя с роботом. На время появления пометки, работа робота приостанавливается в ожидании действий пользователя. |
| 10  | Получить голоса                		| Активность позволяет получить список синтезированных голосов, имеющихся в системе Windows для их дальнейшего использования. |
| 11  | Пользовательский ввод               | Активность позволяет использовать диалоговое окно, созданное не в Primo RPA Studio. В данном примере диалог ввода создан в формате HTML.  |
| 12  | Удалить поля журнала                | Активность используется, для удаления ранее добавленных дополнительных полей в журнал.  |
