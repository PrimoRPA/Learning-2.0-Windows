# Буфер обмена

| №  | Название активности | Краткое описание процесса |
|----|--------------------------------------|----------------------------------------------------|
| 1  | Отправить в буфер обмена				| Пример процесса применения компонента "Отправить в буфер обмена". Данный компонент позволяет отправить какую либо информацию в буфер обмена компьютера. В данном примере в буфер обмена отправляется строка "Primo RPA Studio Learning". |
| 2  | Получить из буфера обмена            | Пример процесса применения компонента "Получить из буфера обмена". Данный компонент позволяет получить данные из буфера обмена компьютера и записать их в переменную типа Object. В прмере из буфера обмена получаем строку "Primo RPA Studio Learning". |
