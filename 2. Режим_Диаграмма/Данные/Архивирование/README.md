# Архивирование

Элементы для упаковки и распаковки архивов.

## 📋 Элементы

| Элемент | Что делает и когда нужен |
| :--- | :--- |
| **Создать архив** | Упаковывает файлы или папку в архив. Нужен, когда результат работы робота нужно отправить одним файлом (например, приложить к письму) или уменьшить объём перед передачей. |
| **Извлечь архив** | Распаковывает архив в указанную папку. Нужен, когда входные данные приходят в архиве — например, выгрузка из системы или вложение из письма. |
