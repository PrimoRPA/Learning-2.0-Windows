# Маппинг

| №  | Название активности | Краткое описание процесса |
|----|--------------------------------------|----------------------------------------------------|
| 1  | Создать маппинг						| Компонент позволяет создать маппинг переменных на аргументы вызываемой последовательности. В примере осуществлен процесс создания новоно маппинга, в котором занесены множество переменных. Данный компонент удобен тем, что объединив множество переменных, можно передавать одним аргументом в другой функциональный блок. |
| 2  | Обновить маппинг                		| Компонент позволяет обновлять данные в уже существующем маппинге. |
