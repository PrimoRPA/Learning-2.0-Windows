# Маппинг

Элементы для объединения нескольких переменных в один именованный набор — удобно передавать между процессами.

## 📋 Элементы

| Элемент | Что делает и когда нужен |
| :--- | :--- |
| **Создать маппинг** | Собирает несколько переменных в один именованный набор (маппинг), который можно передать как единый аргумент в другой процесс или последовательность. Удобен, когда в подпроцесс нужно передать сразу много данных, не описывая для каждой отдельный аргумент. |
| **Обновить маппинг** | Меняет значения внутри уже созданного маппинга, не пересоздавая его заново. |
