# Изображения

| №  | Название активности | Краткое описание процесса |
|----|--------------------------------------|----------------------------------------------------|
| 1  | Обесцветить изображения				| Компонент позволяет конвертировать цветное изображение в черно-белое. В примере осуществлен процесс обесцвечивания изображения из файла .\Дополнительные материалы\Изображение\Входные данные\web.png в файл .\Дополнительные материалы\Изображение\Выходные данные\grayweb.png |
| 2  | Отразить изображение                 | Компонент позволяет отразить изображение в нужную сторону. В примере осуществлен процесс отражения изображения по горизонтали .\Дополнительные материалы\Изображение\Входные данные\web.png |
| 3  | Повернуть изображение				| Компонент позволяет повернуть изображение на заданный угол. В примере осуществлен процесс поворота изображения на 90 градусов по часовой стрелке. |
| 4  | Сохранить изображение			    | Компонент позволяет сохранить изображение в заданном формате. В примере осуществлен процесс сохранения скриншота в формате png. |
