# Дата

Элементы для работы с датой и временем: получение, преобразование, вычисления.

## 📋 Элементы

| Элемент | Что делает и когда нужен |
| :--- | :--- |
| **Текущая дата** | Возвращает текущую дату и время из системных часов. Отправная точка почти для любых операций с датами: отчётный период, срок действия, момент создания файла. |
| **Дата к строке** | Превращает дату в текст нужного формата — например, для имени файла (`2026-09-10`) или для вывода в отчёте. |
| **Строка к дате** | Обратное преобразование: текст с датой превращает в настоящую дату, с которой можно вычислять — сравнивать, прибавлять дни и т.д. |
| **Изменить дату** | Прибавляет или отнимает от даты дни, месяцы или годы. Нужен для расчёта сроков — например, «через 30 дней от сегодня» или «минус 5 лет для проверки возраста». |
| **Разница дат** | Считает, сколько времени прошло между двумя датами. Нужен для проверки просрочек, стажа, срока действия документа. |
| **Часть даты** | Достаёт из даты отдельную часть — только год, только месяц и т.д. Нужен, например, чтобы сгруппировать записи по году без учёта дня и месяца. |
