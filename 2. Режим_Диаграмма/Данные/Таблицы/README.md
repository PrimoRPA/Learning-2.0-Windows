# Таблицы

##Данные активности применяются только к переменным с типом данных System.Data.DataTable. 

| №  | Название активности | Краткое описание процесса |
|----|--------------------------------------|----------------------------------------------------|
| 1  | Добавить столбец						| Компонент позволяет добавить новый столбец к существующей таблице с типом данных "System.Data.DataTable". В примере осуществлен процесс добавления столбца "Номер телефона" к сущесвующей DataTable. |
| 2  | Добавить строку                 		| Компонент позволяет добавить новую строку к существующей таблице с типом данных "System.Data.DataTable". В примере осуществлен процесс добавления новой строки с данными к сущесвующей DataTable. |
| 3  | Искать в таблице						| Компонент позволяет находить значение или номер строки в таблице с типом данных "System.Data.DataTable". В примере осуществлен процесс поиска данных "ДЖАСТ" в сущесвующей DataTable. |
| 4  | Объединить таблицы			    	| Компонент позволяет объединить две таблицы с типом данных "System.Data.DataTable". В примере осуществлен процесс объединения двух таблиц, считанных из файлов @".\Дополнительные материалы\Данные\ИНН.xlsx" и @".\Дополнительные материалы\Данные\ИНН2.xlsx". |
| 5  | Очистить таблицу			    		| Данный компонент позволяет очистить все существующие данные из таблицы с типом данных "System.Data.DataTable", но структура таблицы сохраняется. В примере осуществлен процесс очистки таблицы, считанной из файла @".\Дополнительные материалы\Данные\ИНН.xlsx". |
| 6  | Создать таблицу			    		| Компонент позволяет создать новую пустую таблицу с типом данных "System.Data.DataTable" с определенным количеством столбцов и названием. В примере создается новая таблица с названиями колонок "Col1", "Col2" и "Col3". |
| 7  | Сортировать таблицу					| Данный компонент позволяет отсортировать таблицу с типом данных "System.Data.DataTable" по столбцу в порядке возрастания или убывания. В примере осуществлен процесс считывания таблицы из файла @".\Дополнительные материалы\Данные\ИНН.xlsx" и далее таблица сортируется по возрастанию по колонке с названием "Имя". |
| 8  | Удалить колонку						| Данный компонент производит удаление колонки из существующей таблицы с типом данных "System.Data.DataTable". В примере осуществлен процесс счтывания из файла @".\Дополнительные материалы\Данные\ИНН.xlsx" таблицы с данными и далее производится удаление столбца с названием "Имя". |
| 9  | Удалить повторяющиеся строки	   		| Компонент позволяет удалить повторяющиеся строки из существующей таблицы с типом данных "System.Data.DataTable". В примере осуществлен процесс счтывания таблицы из файла @".\Дополнительные материалы\Данные\ИНН2.xlsx" и далее производится удаление повторяющихся строк из таблицы. |
| 10  | Удалить строку                 		| Компонент позволяет удалить строку из существующей таблицы с типом данных "System.Data.DataTable". Удаление строки осуществляется по индексу строки. Отсчет строк начинается с нуля. В примере осуществлен процесс счтывания таблицы из файла @".\Дополнительные материалы\Данные\ИНН.xlsx" и далее осуществляется удаление второй строки по индексу. |
