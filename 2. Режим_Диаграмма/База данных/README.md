# База данных

| №  | Название активности | Краткое описание процесса |
|----|--------------------------------------|----------------------------------------------------|
| 1  | Вставка данных          				| Пример процесса вставки данных в существующую базу данных. В процессе создаётся новая таблица, добавление в таблицу данных. В виде базы данных используется файл Excel. Компонент "Вставка данных" должен находиться внутри компонента "Присоединиться к БД". |
| 2  | Выполнить запрос                     | Пример процесса выполнения SQL запроса в существующей базе данных. В виде базы данных используется файл Excel. Компонент "Выполнить запрос" должен находиться внутри компонента "Присоединиться к БД". Результат выполнения запроса записывается в переменную dtExcelInfo. |
| 3  | Отсоединиться от БД               	| Пример процесса отсоединения от существующей базы данных. В виде базы данных используется файл Excel. Компонент "Отсоединиться от БД" должен находиться внутри компонента "Присоединиться к БД".|
| 4  | Присоединиться к БД          		| Пример процесса присоединения к базам данных различных типов, таких как ODBC, Postgre Sql и Ole DB. Данный компонент является контейнером для активностей "Вставка данных", "Выполнить запрос" и "Отсоединиться от БД". |
