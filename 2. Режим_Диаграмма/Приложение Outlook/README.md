# Приложение Outlook

Элементы для автоматизации работы с Microsoft Outlook через установленное приложение.
> **При использовании активностей данного раздела, Outlook может выдавать сообщение, чтобы пользователь подтвердил отправку письма. Чтобы отключить появление такого сообщения, необходимо настроить Outlook: Параметры -> Центр управления безопасностью -> Параметры центра управления безопасностью... -> Программный доступ -> Никогда не предупреждать о подозрительной активности.**

> **«Приложение Outlook»** — контейнер. Остальные элементы раздела должны находиться внутри него. На рабочей машине должен быть установлен и настроен MS Outlook. 

> Если на машине нет Outlook или нужна работа с корпоративным Exchange-сервером напрямую — используйте раздел [Почта / MS Exchange](../Почта/MS%20Exchange).

## 📋 Элементы

| Элемент | Что делает и когда нужен |
| :--- | :--- |
| **Приложение Outlook** | Подключается к установленному Outlook и открывает сессию работы с ним. Контейнер — без него остальные элементы не работают. |
| **Чтение почты** | Считывает письма из указанной папки (Входящие, Отправленные и т.д.) с фильтрацией по теме, отправителю или дате. Основной способ получить письма через Outlook. |
| **Отправить сообщение** | Создаёт и отправляет письмо с указанными получателями, темой, телом и вложениями. |
| **Переместить в папку** | Перемещает обработанные письма в другую папку. Нужен для разметки ящика — например, перекладывать в «Обработано» после каждого письма. |
| **Пометить сообщения** | Устанавливает статус письма: прочитано, важное и т.д. Нужен, чтобы отметить обработанные письма и не захватывать их повторно. |
| **Синхронизировать папку** | Принудительно синхронизирует папку с сервером. Нужен, если нужны самые свежие письма, не дожидаясь автообновления Outlook. |
| **Сохранить вложение** | Сохраняет вложения письма на диск. Нужен, когда входящие письма содержат файлы для обработки. |
| **Сохранить сообщение** | Сохраняет письмо целиком на диск. |
| **Читать адресную книгу** | Считывает контакты из адресной книги Outlook. Нужен, когда список адресатов хранится в контактах Outlook, а не в отдельном файле. |
| **Закрыть Outlook** | Корректно завершает работу с Outlook. Рекомендуется ставить в конце процесса. |
