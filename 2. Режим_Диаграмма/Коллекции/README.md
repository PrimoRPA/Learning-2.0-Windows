# Коллекции


| №  | Название активности | Краткое описание процесса |
|----|--------------------------------------|----------------------------------------------------|
| 1  | Добавить в массив					| Элемент осуществляющий добавление нового значения в имеющийся массив данных. В примере осуществлен процесс создания списка, и с помощью активности "Добавить в массив" осуществлено добавление нового элемента. |
| 2  | Таблицу в CSV               			| Активность используется для преобразования таблицы типа данных System.Data.DataTable в строковую переменную с добавлением определенного разделителя. В примере осуществлен процесс создания таблицы dtDataFromTable, добавления в неё данных и далее осуществлено преобразование в строковую переменную strTableInCsv с разделителем. |
| 3  | Фильтр таблицы                		| Элемент предназначен для осуществления фильтрации таблицы типа данных System.Data.DataTable по заданным параметрам. В примере осуществлен процесс создания новой таблицы dtDataFromTable, добавления в неё данных. Далее осуществлено фильтрование таблицы по колонке "Группа". |
