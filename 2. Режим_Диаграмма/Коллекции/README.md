# Коллекции

Элементы для работы с коллекциями данных: массивами и таблицами.

## 📋 Элементы

| Элемент | Что делает и когда нужен |
| :--- | :--- |
| **Добавить в массив** | Добавляет элемент в существующий список (List). Нужен, когда результаты обработки накапливаются по одному — например, собирать ID записей в цикле, а потом обработать всё разом. |
| **Фильтр таблицы** | Отбирает строки DataTable по условию в новую таблицу. Нужен, когда из большого набора данных нужна только часть — например, только строки со статусом «Новый» или с суммой выше порога. |
| **Таблицу в CSV** | Преобразует DataTable в строку CSV с заданным разделителем. Нужен, когда результат работы нужно сохранить в CSV-файл или передать системе, принимающей только CSV. |
