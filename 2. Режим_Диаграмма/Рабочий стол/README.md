# Рабочий стол

Элементы для управления окнами и процессами операционной системы: запуск и завершение приложений, управление окнами, снимки экрана, эмуляция ввода.

## 📋 Элементы

| Элемент | Что делает и когда нужен |
| :--- | :--- |
| **Запустить приложение** | Запускает внешнее приложение по пути к исполняемому файлу. Нужен в начале процессов, где робот работает с конкретным приложением — 1С, SAP, десктопная CRM. |
| **Присоединиться к приложению** | Подключается к уже запущенному окну приложения по имени или заголовку. Контейнер для работы с UI этого приложения. Нужен, когда приложение уже открыто, а не запускается роботом. |
| **Активировать процесс** | Выводит окно приложения на передний план и делает его активным. Нужен, когда приложение свёрнуто или перекрыто другими окнами. |
| **Получить активное окно** | Возвращает информацию об окне, которое сейчас в фокусе. Нужен для проверки — туда ли переключился фокус, прежде чем выполнять следующие шаги. |
| **Развернуть окно** | Разворачивает окно на весь экран. Нужен для приложений, у которых элементы пропадают при неполном размере окна. |
| **Свернуть окно** | Сворачивает окно в панель задач. |
| **Восстановить окно** | Возвращает окно к нормальному размеру после свёртки или разворота. |
| **Завершить приложение** | Корректно закрывает приложение. Нужен в конце процесса, чтобы не оставлять лишних процессов. |
| **Уничтожить процесс** | Принудительно завершает зависший процесс. Нужен, когда приложение не реагирует и не закрывается штатно. |
| **Список процессов** | Возвращает список запущенных процессов ОС. Нужен, чтобы проверить, запущено ли нужное приложение перед попыткой к нему подключиться. |
| **Снимок рабочего стола** | Делает скриншот экрана или окна и сохраняет в файл или переменную. Нужен для фиксации состояния экрана — при ошибках, для логов или передачи в OCR. |
| **Запись видео рабочего стола** | Записывает видео происходящего на экране. Нужен для документирования работы робота или отладки сложных сценариев. |
| **Чтение таблицы** | Считывает данные табличного элемента интерфейса (grid, list view) в DataTable. Нужен, когда приложение показывает данные в таблице, а API или экспорт недоступны. |
| **Эмуляция ввода текста** | Вводит текст через механизм ОС (SendKeys). Нужен для приложений, которые не воспринимают стандартный ввод элемента «Ввод текста». |
| **Эмуляция спецкнопки** | Нажимает специальную клавишу или сочетание (Enter, Tab, F5, Ctrl+S и т.д.) через ОС. Нужен, когда нужного элемента нет в интерфейсе, но действие вызывается горячей клавишей. |
| **Прочитать консоль** | Считывает вывод консольного приложения. Нужен, когда результат работы внешней программы отображается в консоли. |
| **Блокировка ввода** | Блокирует клавиатуру и мышь пользователя на время работы робота. Нужен, чтобы пользователь случайно не помешал процессу — например, не кликнул не туда. |
| **Разрешение** | Получает или изменяет разрешение экрана. Нужен, когда робот работает с приложением, чувствительным к разрешению. |
| **Раскладка** | Получает или устанавливает раскладку клавиатуры. Нужен, когда приложение ведёт себя по-разному при разных раскладках. |
