# База данных

Элементы для подключения к базам данных и выполнения SQL-запросов. Поддерживаются ODBC, OLE DB, PostgreSQL и другие источники, в том числе Excel как база данных.

> **«Присоединиться к БД»** — контейнер, внутри которого должны находиться все остальные элементы этого раздела. Так же можно использовать остальные элементы без этого контейнера, но предварительно необходимо создать инстанс соединения с БД в этом контейнере (например, в начале проекта).

## 📋 Элементы

| Элемент | Что делает и когда нужен |
| :--- | :--- |
| **Присоединиться к БД** | Устанавливает соединение с базой данных и открывает сессию для работы с ней. |
| **Выполнить запрос** | Выполняет произвольный SQL-запрос (SELECT, UPDATE, INSERT и т.д.) и, при необходимости, возвращает результат в DataTable. Основной рабочий инструмент раздела. |
| **Вставка данных** | Записывает таблицу DataTable в базу данных одной операцией — быстрее, чем вставлять строки по одной через SQL. Нужен при массовой загрузке данных. |
| **Отсоединиться от БД** | Явно закрывает соединение с базой данных до выхода из контейнера. Нужен, если соединение нужно закрыть в разных ветках проекта. |
