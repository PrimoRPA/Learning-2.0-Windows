# Браузер

## Компненты "Открыть браузер" и "Присоединиться к браузеру" являются контейнерами и использование остальных компонентов необходимо производить внутри контейнера. Для работы данных компонентов необходимо установить расширение для предпочитаемого браузера. Чтобы это сделать воспользуйтесь гайдом:https://docs.primo-rpa.ru/primo-rpa/primo-rpa-studio/settings/plugin-install.

## В данных примерах используется браузер Google Chrome.

| №  | Название активности | Краткое описание процесса |
|----|--------------------------------------|----------------------------------------------------|
| 1  | Активировать вкладку браузера		| Пример процесса применения компонента. Процесс выполняет открытие браузера на сайте google.com, открытие новой вкладки на сайте docs.primo-rpa.ru, активация вкладки google.com, закрытие браузера. |
| 2  | Активная вкладка                     | Пример процесса получения информации об активной вкладки браузера. Процесс выполняет открытие браузера на странице google.com, извлечение информации об активной вкладке и закрытие браузера. Информация записывается в переменную pageInfo. |
| 3  | Вперёд				               	| Пример процесса использования компонента "Вперед". Данный компонент позволяет перейти на следующую страницу сайта, если предыдущим действием был переход на страницу назад. |
| 4  | Выполнить JS			          		| Пример процесса выполнения скрипта JS в браузере. Процесс выполняет открытие браузера на странице google.com, выполнение JS скрипта и закрытие браузера. |
| 5  | Закрыть браузер		  				| Пример процесса закрытия браузера. Процесс выполняет открытие браузера на странице google.com, далее происходит закрытие браузера. |
| 6  | Закрыть вкладку браузера             | Пример процесса закрытия вкладкки браузера. Данный компонент позволяет закрыть определенный вкладку по её заголовку или индексу. Процесс выполняет открытие браузера на странице google.com, открытие новой вкладки на странице docs.primo-rpa.ru, далее происходит закрытие вкладки google.com. |
| 7  | Назад								| Пример процесса использования компонента "Назад". Данный компонент позволяет произвести навигацию на сайте на страницу назад. Процесс выполняет открытие браузера на странице docs.primo-rpa.ru/primo-rpa, клик мышью по кнопке "Полезные ресурсы" и навигацию на страницу назад. |
| 8  | Обновить		                 		| Пример процесса использования компонента "Обновить". Данный компонент позволяет обновить текущую страницу в браузере. Процесс выполняет открытие браузера на странице google.com, ожидание полной загрузки страницы, выполнение обновления страницы. |
| 9  | Открыть браузер                 		| Компонент "Открыть браузер" является контейнером. Позволяет открыть браузер определенного типа на указанной в свойствах странице сайта. В данном примере открывается браузер Google Chrome на странице google.com. |
| 10 | Открыть вкладку браузера        		| Пример процесса использования компонента "Открыть вкладку браузера". Процесс выполняет открытие браузера на странице google.com, далее открывается новая вкладка на странице docs.primo-rpa.ru. |
| 11 | Перейти к странице              		| Пример процесса использования компонента "Перейти к странице". Данный компонент позволяет переход на другую страницу по URL на текущей активной вкладке. Процесс выполняет открытие браузера на странице google.com, ожидание полной загрузки страницы, далее происходит переход к странице dzen.ru на текущей активной вкладке. |
| 12 | Получить атрибут               		| Пример процесса использования компонента "Получить атрибут". Данный компонент позволяет получение любого указанного атрибута элемента управления. Процесс выполняет открытие браузера на странице google.com, далее выполняется получение атрибута "src". |
| 13 | Присоединиться к браузеру       		| Компонент "Присоединиться к браузеру" является контейнером. Позволяет присоединиться к уже открытому браузеру к указанной вкладке. |
| 14 | Прочитать таблицу               		| Пример процесса использования компонента "Прочитать таблицу". Позволяет извлечь табличные данные со страницы браузера. В данном примере выполняется открытие браузера на странице cbr.ru и считывание данных о текущих курсах валют. Данные записываются в переменную dtInfo типа System.Data.DataTable. |
| 15 | Скачать изображение             		| Пример процесса использования компонента "Скачать изображение". В данном примере выполняется скачивание изображения по ссылке на это изображение. |
