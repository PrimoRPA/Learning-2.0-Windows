# Приложение Excel

Элементы для автоматизации работы с файлами Microsoft Excel: чтение и запись данных, форматирование, работа с листами, диаграммами, формулами и макросами.

> **«Приложение Excel»** — контейнер. Все остальные элементы раздела должны находиться внутри него.

## 📋 Элементы

| Элемент | Что делает и когда нужен |
| :--- | :--- |
| **Приложение Excel** | Открывает или создаёт файл Excel и начинает сессию работы с ним. Контейнер — без него ни один другой элемент раздела не работает. |
| **Чтение из ячейки** | Считывает значение одной конкретной ячейки. Нужен, когда нужно взять одно фиксированное значение — например, заголовок отчёта или дату формирования. |
| **Ввод в ячейку** | Записывает значение в одну конкретную ячейку. Нужен для точечного заполнения — например, поставить итог в конкретную ячейку. |
| **Чтение формулы из ячейки** | Возвращает текст формулы, а не результат её вычисления. Нужен, когда важна сама формула, а не её значение. |
| **Ввод формулы в ячейку** | Вставляет формулу в ячейку. Нужен, когда результат должен пересчитываться самим Excel, а не быть жёстко заданным. |
| **Чтение диапазона** | Считывает прямоугольный диапазон ячеек в DataTable. Основной способ загрузить табличные данные из Excel для обработки. |
| **Запись диапазона** | Записывает DataTable в диапазон ячеек. Основной способ выгрузить результаты обработки обратно в Excel. |
| **Чтение колонки** | Считывает весь столбец в список. Быстрее, чем читать диапазон, когда нужна только одна колонка. |
| **Поиск в диапазоне** | Ищет значение в заданном диапазоне и возвращает его координаты. Нужен, чтобы найти конкретную запись без перебора всей таблицы. |
| **Поиск на странице** | Ищет значение по всему листу. Нужен, когда точное расположение данных заранее не известно. |
| **Найти начальную/конечную строку** | Определяет номер первой или последней заполненной строки в столбце. Нужен для динамических диапазонов — когда таблица каждый раз другого размера. |
| **Выделение диапазона** | Выделяет диапазон ячеек, как если бы пользователь выделил их мышью. Нужен перед операциями, которые работают только с выделением. |
| **Копирование диапазона** | Копирует диапазон ячеек в другое место листа или в другой лист. |
| **Удаление диапазона** | Очищает значения в диапазоне ячеек. |
| **Вставка строк** | Вставляет пустые строки в указанное место. Нужен, когда в существующую таблицу нужно добавить место для новых данных. |
| **Вставка колонок** | Вставляет пустые столбцы. |
| **Удаление строк** | Удаляет строки с листа. |
| **Удаление колонок** | Удаляет столбцы с листа. |
| **Фильтр диапазона** | Применяет автофильтр к диапазону по заданному условию. Нужен, когда нужно скрыть строки прямо в Excel, а не фильтровать в DataTable. |
| **Сортировка диапазона** | Сортирует диапазон по значению столбца прямо в Excel. |
| **Создать таблицу** | Создаёт именованную «умную таблицу» (Table) на листе. Нужен, когда диапазон будет использоваться как источник данных с автофильтрами и формулами. |
| **Получение диапазона таблицы** | Возвращает диапазон, который занимает именованная таблица. Нужен, чтобы работать с таблицей по имени, не зная её координат заранее. |
| **Изменение ячейки** | Изменяет форматирование ячейки: фон, границы, выравнивание. Нужен для оформления отчётов прямо из процесса. |
| **Изменение шрифта** | Изменяет параметры шрифта: размер, жирность, цвет. |
| **Вставка диаграммы** | Вставляет диаграмму на лист Excel. Нужен, когда отчёт должен содержать графики, а не только числа. |
| **Редактировать диаграмму** | Меняет тип или данные существующей диаграммы. |
| **Запустить макрос** | Выполняет VBA-макрос, уже записанный в файле. Нужен, когда в Excel есть готовая бизнес-логика на VBA, которую не нужно переписывать. |
| **Запустить VBA** | Выполняет VBA-функцию из кода процесса напрямую. |
| **Пересчет формул** | Принудительно пересчитывает все формулы книги. Нужен после массовой записи данных, если Excel не пересчитал результаты автоматически. |
| **Обновление данных соединений** | Обновляет внешние источники данных (Power Query, ODBC-соединения). Нужен, если в книге есть подключения к базам данных или другим файлам. |
| **Установить пароль** | Защищает файл паролем на открытие. |
| **Сохранить документ** | Сохраняет текущий файл. Обязательно ставить в конце работы — без него изменения пропадут. |
| **Сохранить как PDF** | Экспортирует файл Excel в PDF. Нужен, когда готовый отчёт нужно отправить в нередактируемом виде. |
