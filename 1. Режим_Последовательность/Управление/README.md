# Управление


| №  | Название активности | Краткое описание процесса |
|----|--------------------------------------|----------------------------------------------------|
| 1  | Последовательность					| Компонент предназначен для группировки набора активностей в логический блок с последовательным выполнением, что упрощает структурирование и повторное использование кода. |
| 2  | If-Else								| Компонент предназначен для выполнения одной из двух веток действий в зависимости от результата логического условия (истина/ложь). |
| 3  | Switch								| Компонент предназначен для выбора одной из множества веток выполнения на основе значения переменной или выражения с поддержкой значений по умолчанию. |
| 4  | Ветвь								| Компонент предназначен для размещения в контейнере "Выбрать ветвь". Для ветви настраивается "Триггер" и "Действие", выполняемое при срабатывании этого триггера. |
| 5  | Выбрать ветвь						| Контейнер, в котором можно разместить две и более ветвей. В параллельном режиме запускается ожидание срабатывания триггера одной из ветвей. Срабатывание триггера происходит после того, как в блоке "Действие" возрашается значение true. |
| 6  | Цикл While							| Компонент предназначен для повторного выполнения блока активностей до тех пор, пока заданное условие остаётся истинным (проверка перед каждой итерацией). |
| 7  | Цикл Do-While						| Компонент предназначен для выполнения блока активностей с последующей проверкой условия, гарантируя как минимум одну итерацию цикла. |
| 8  | Цикл ForEach							| Компонент предназначен для перебора всех элементов в коллекции, массиве или списке с автоматической передачей текущего элемента в переменную на каждой итерации. |
| 9  | Цикл ForEach для DataTable			| Компонент предназначен для итерации по строкам таблицы данных (DataTable) с возможностью доступа к значениям ячеек по имени столбца или его индексу. |
| 10  | Повтор N раз						| Компонент предназначен для выполнения блока активностей строго заданное количество раз с автоматическим счётчиком итераций. |
| 11  | Повтор попыток						| Компонент предназначен для повтора попытки выполнения действия либо заданное число раз, либо до тех пор, пока не выполнится определенное условие. |
| 12  | Повтор исключений					| Компонент вызывает повторное исключение из блока Catch в контейнере Try-Catch. |
| 13  | Try-Catch							| Компонент предназначен для перехвата и обработки исключений, возникающих при выполнении блока активностей, с возможностью выполнения альтернативных действий в случае ошибки. |
| 14  | Исключение							| Компонент предназначен для генерации пользовательского исключения с заданным сообщением и типом ошибки для управления потоком выполнения или сигнализации о проблемах. |
| 15  | Выход из цикла						| Компонент предназначен для досрочного прерывания выполнения цикла и перехода к следующей активности за его пределами. |
| 16  | Продолжить цикл						| Компонент предназначен для немедленного перехода к следующей итерации цикла без выполнения оставшихся активностей в текущей итерации. |
| 17  | Выход из процесса					| Компонент предназначен для немедленного завершения выполнения текущего процесса или сценария независимо от того, есть ли поэле этого компонента другие действия. |
| 18  | Параллельные потоки					| Компонент предназначен для одновременного выполнения нескольких блоков активностей в отдельных потоках с последующим объединением результатов. |
| 19  | Ожидание							| Компонент предназначен для приостановки выполнения сценария на заданный промежуток времени в миллисекундах. |
| 20  | Присвоение							| Компонент предназначен для присвоения значения переменной. |
| 21  | Множественное присвоение			| Компонент предназначен для присвоения значений множеству переменных в одной активности. |
| 22  | Ссылка на процесс					| Компонент предназначен для вызова другого процесса или сценария из текущего проекта с передачей параметров и получением возвращаемых значений. |
| 23  | Закомментировать					| Компонент предназначен для временного отключения блока активностей без их удаления, что позволяет сохранить логику для отладки или будущего использования. |
