# Диаграмма

Элементы для построения логики в режиме диаграммы (Flowchart) прямо внутри последовательности.

> Это элементы, которые позволяют встроить блок-схему внутрь обычной последовательности — когда в одном месте нужна разветвлённая логика, а остальной процесс остаётся линейным.

## 📋 Элементы

| Элемент | Что делает и когда нужен |
| :--- | :--- |
| **Диаграмма** | Контейнер, внутри которого строится логика в виде блок-схемы. Нужен, когда конкретный участок процесса требует сложных разветвлений, а вся остальная часть — линейная. |
| **Последовательность** | Контейнер внутри диаграммы, объединяющий несколько шагов в один блок. Нужен для логической группировки — чтобы диаграмма не превращалась в хаос из отдельных элементов. |
