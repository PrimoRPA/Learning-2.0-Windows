# Программирование


| №  | Название активности | Краткое описание процесса |
|----|--------------------------------------|----------------------------------------------------|
| 1  | C# Script							| Компонент предназначен для выполнения фрагментов кода на языке C# непосредственно в процессе выполнения сценария с возможностью обращения к переменным проекта и возврата результатов вычислений. В примере осуществлен процесс вызова C# кода, который выводит сообщение "Привет, Primo!". |
| 2  | Python Script          				| Компонент предназначен для запуска скриптов на языке Python с передачей входных параметров и получением выходных данных. В примере осуществлен процесс вызова Python кода, который выводит сообщение "Привет, Primo!". |
| 3  | JavaScript         					| Компонент предназначен для выполнения кода на языке JavaScript. В примере осуществлен процесс вызова JavaScript кода, который выводит сообщение "Привет, Primo!". |
| 4  | Power Shell           				| Компонент предназначен для запуска скриптов Windows PowerShell. Код может быть как однострочным так и многострочным. В примере осуществлен процесс вызова PowerShell скрипта, который выводит сообщение "Привет, Primo!". |
| 5  | Выполнить скрипт VB       			| Компонент предназначен для выполнения кода на языке VBScript. Для успешного запуска данной активности, необходимо указать путь до файла с VB скриптом. |
| 6  | Вызов метода       					| Компонент предназначен для вызова однострочного сценария на языке программирования, выбранном при создании проекта. В примере осуществлен процесс вызова метода на C#, который выводит сообщение "Привет, Primo!". |
| 7  | Командная строка     				| Компонент предназначен для выполнения консольной команды CMD. |
