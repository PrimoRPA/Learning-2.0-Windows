# Программирование

Элементы для выполнения пользовательского кода прямо внутри процесса — когда стандартных элементов студии недостаточно.

## 📋 Элементы

| Элемент | Что делает и когда нужен |
| :--- | :--- |
| **C# Script** | Выполняет произвольный код на C# с доступом к переменным процесса. Самый гибкий вариант — C# позволяет делать практически что угодно: сложные вычисления, работу с файлами, вызов библиотек. |
| **Python Script** | Выполняет Python-скрипт. Нужен, когда логика уже написана на Python (анализ данных, ML, парсинг) и её проще использовать напрямую, чем переписывать. |
| **JavaScript** | Выполняет JavaScript-код. Нужен, когда требуется обработка JSON или взаимодействие с веб-технологиями из кода. |
| **Power Shell** | Запускает PowerShell-скрипт. Нужен для системного администрирования: управление службами, реестром, AD, работа с файловой системой через PowerShell. |
| **Выполнить скрипт VB** | Выполняет скрипт VBScript из файла. Нужен, когда есть готовый скрипт на VB, который не хочется переписывать. |
| **Вызов метода** | Вызывает метод произвольного .NET-объекта или класса. Нужен, когда нужна возможность .NET-библиотеки, но писать полноценный C# скрипт избыточно. |
| **Командная строка** | Выполняет команду в командной строке Windows (cmd). Нужен для запуска внешних утилит, пакетных файлов или системных команд. |
