# Очереди

##Все элементы группы "Оркестратор" работают только в Primo RPA Studio Enterprise. Необходим подключенный оркестратор к студии.

| №  | Название активности | Краткое описание процесса |
|----|--------------------------------------|----------------------------------------------------|
| 1  | Добавить в очередь					| Компонент добавляет новый элемент в очередь обмена данными Оркестратора.  |
| 2  | Изменить статус в очереди            | Компонент позволяет изменить статус элемента очереди обмена данных Оркестратора на Успешно, Ошибка или Ошибка в бизнес логике. В примере осуществлен процесс получения элемента очереди и изменение его статуса. |
| 3  | Ожидать сообщения из очереди         | Компонент ожидает появления нового элемента в очереди обмена данными. Чтобы элемент заработал, нужно указать имя очереди, из которой робот извлечёт элемент, и период ожидания — время, в течение которого робот будет проверять очередь. |
| 4  | Получить из очереди по ID            | Компонент предоставляет возможность извлечь определённый элемент из очереди, используя его уникальный идентификатор (Id). В примере осуществлен процесс получения списка элементов очереди по фильтру и получение первого элемента по его ID. |
| 5  | Получить из очереди по фильтру       | Компонент позволяет получить элементы очереди, подходящие под заданный фильтр. В примере осуществлен процесс получения списка элементов очереди по фильтру со статусом "Ошибка в бизнес логике" и текущей дате. |
| 6  | Получить из очереди              	| Компонент позволяет получить данные из очереди оркестратора. В примере осуществлен процесс получения первого элемента очереди со статусом "Новый". |
| 7  | Удалить из очереди              		| Компонент позволяет удалить любой элемент из указанной очереди по его ID. В примере осуществлен процесс получения первого элемента очереди со статусом "Новый" и удаление этого элемента из очереди. |
