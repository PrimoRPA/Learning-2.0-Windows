# Оркестратор / Очереди

Элементы для работы с очередями обмена данными Оркестратора — основным механизмом передачи заданий между роботами и внешними системами.

> ⚠️ Требуется **Primo RPA Studio Enterprise** с подключённым Оркестратором.

## Как это работает

Очередь — это список заданий в Оркестраторе. Один робот (или внешняя система) кладёт задания в очередь, другой робот забирает их по одному и обрабатывает. Это стандартный способ масштабировать RPA: вместо одного большого процесса — два маленьких, которые можно запускать независимо и параллельно.

## 📋 Элементы

| Элемент | Что делает и когда нужен |
| :--- | :--- |
| **Добавить в очередь** | Кладёт новое задание (с данными) в указанную очередь. Нужен роботу-«отправителю» — тому, кто формирует список заданий: например, читает строки из Excel и превращает каждую в задание для другого робота. |
| **Получить из очереди** | Берёт первое необработанное задание из очереди (статус «Новый»). Основной элемент робота-«обработчика» — забрать следующее задание и начать с ним работать. |
| **Получить из очереди по ID** | Берёт конкретное задание по его уникальному ID. Нужен, когда нужно вернуться к определённому заданию — например, перепроверить или повторить обработку конкретной записи. |
| **Получить из очереди по фильтру** | Возвращает список заданий, подходящих под условие (статус, дата и т.д.). Нужен для анализа очереди — например, найти все задания со статусом «Ошибка» за сегодня и повторить их. |
| **Ожидать сообщения из очереди** | Блокирует процесс до появления нового задания в очереди, затем сразу его забирает. Нужен для событийных роботов, которые не опрашивают очередь по расписанию, а висят и ждут. |
| **Изменить статус в очереди** | Устанавливает статус обработки задания: «Успешно», «Ошибка» или «Бизнес-ошибка». Обязательно ставится после обработки каждого задания — чтобы Оркестратор знал результат и не отдал это задание снова. |
| **Удалить из очереди** | Удаляет задание из очереди по ID. Нужен, когда задание больше не актуально и обрабатывать его не нужно — например, дубликат или отменённый заказ. |
