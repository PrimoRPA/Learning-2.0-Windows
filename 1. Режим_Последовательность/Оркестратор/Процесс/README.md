# Процесс

##Все элементы группы "Оркестратор" работают только в Primo RPA Studio Enterprise. Необходим подключенный оркестратор к студии.

| №  | Название активности | Краткое описание процесса |
|----|--------------------------------------|----------------------------------------------------|
| 1  | Вызов проекта						| Активность «Вызов проекта» в Primo RPA позволяет запустить другой проект из текущего, чтобы обработать его локально. Данная активность может работать без подключения к оркестратору даже в Primo RPA Studio Community версии, указав только путь к подпроцессу. В примере осуществлен процесс в котором вызывается подпроцесс RPA Challenge Basic.ltw. |
| 2  | Должен остановиться            		| Элемент определяет, поступила ли команда на мягкую остановку робота из системы Оркестратор. Результат проверки сохраняется в виде логического значения в свойстве «Результат». В зависимости от полученного значения следует делать развилку на последующие действия. Это может быть заверешние процесса в целом или выход из какого-либо цикла. |
| 3  | Запустить робота         			| Элемент запускает на выполнение задания по его имени в Оркестраторе. Задание должно быть связано с роботом в настройках задания. |
