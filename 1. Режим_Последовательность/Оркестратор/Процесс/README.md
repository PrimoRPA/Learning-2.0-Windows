# Оркестратор / Процесс

Элементы для управления выполнением процессов и роботов через Оркестратор.

> ⚠️ Элементы «Запустить робота» и «Должен остановиться» требуют **Primo RPA Studio Enterprise** с подключённым Оркестратором. «Вызов проекта» работает и без Оркестратора — в том числе в Community-версии.

## 📋 Элементы

| Элемент | Что делает и когда нужен |
| :--- | :--- |
| **Вызов проекта** | Запускает другой `.ltw`-процесс как подпроцесс — прямо из текущего, локально. Нужен, чтобы разбить большой процесс на переиспользуемые части: общая логика выносится в отдельный файл и вызывается оттуда, где нужна. Работает без Оркестратора. |
| **Запустить робота** | Запускает задание в Оркестраторе по его имени. Нужен, когда один робот должен инициировать запуск другого — например, после подготовки данных передать управление роботу-обработчику. |
| **Должен остановиться** | Проверяет, поступила ли из Оркестратора команда на «мягкую остановку» робота. Нужен внутри длинных циклов: робот сам проверяет этот флаг и корректно завершает итерацию, не обрывая работу на середине. Без этого элемента команда остановки из Оркестратора будет проигнорирована до конца цикла. |
