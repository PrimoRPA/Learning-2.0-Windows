# Форма ввода

Элементы для отображения настраиваемых форм с несколькими полями ввода.

> Форму нужно сначала создать в **Редакторе диалогов** (меню «Инструменты» → «Редактор диалогов»). Подробнее — в [документации](https://docs.primo-rpa.ru/primo-rpa/primo-rpa-studio/tools/dialogs-editor).

## 📋 Элементы

| Элемент | Что делает и когда нужен |
| :--- | :--- |
| **Форма ввода** | Открывает пользователю заранее созданную форму с полями (текст, список, дата и т.д.) и ждёт, пока тот её заполнит. Нужен, когда стандартного диалога на одно поле мало — например, нужно запросить ФИО, дату и тип операции одновременно. |
| **Закрыть форму** | Программно закрывает открытую форму из кода процесса. Нужен в сценариях, когда форма должна закрыться не по кнопке пользователя, а по условию — например, по таймауту. |
