# Изображения

Базовая обработка изображений — часто нужна как подготовительный шаг перед распознаванием текста (OCR) или перед отправкой файла.

## 📋 Элементы

| Элемент | Что делает и когда нужен |
| :--- | :--- |
| **Повернуть изображение** | Поворачивает изображение на нужный угол. Нужен, когда скан или фото пришли в неправильной ориентации — перед распознаванием текста или отправкой дальше. |
| **Отразить изображение** | Зеркалит изображение по горизонтали или вертикали. |
| **Обесцветить изображение** | Убирает цвет, делает изображение чёрно-белым. Иногда повышает точность распознавания текста на сканах. |
| **Сохранить изображение** | Сохраняет изображение (например, скриншот) в файл нужного формата на диске. |
