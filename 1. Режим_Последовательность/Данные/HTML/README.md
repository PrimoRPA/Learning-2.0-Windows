# HTML

Элементы для разбора HTML-разметки без открытия браузера — полезно, когда HTML получен не со страницы сайта, а, например, из письма, файла или ответа API.

## 📋 Элементы

| Элемент | Что делает и когда нужен |
| :--- | :--- |
| **HTML к объекту** | Разбирает HTML-код в объект, по которому удобно искать нужные части — как в браузере, только без самого браузера. Нужен, когда HTML-код есть на руках (из письма, файла, API), а открывать реальную страницу не требуется. |
| **HTML к DataTable** | Превращает HTML-таблицу сразу в DataTable. Удобнее, чем «HTML к объекту», когда заранее известно, что нужна именно таблица, а не произвольный поиск по разметке. |
