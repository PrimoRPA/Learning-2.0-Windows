# Таблицы

Элементы для работы с табличными данными (DataTable) — тем же типом данных, в который считываются диапазоны Excel и Google Sheets.

> Активности этого раздела применяются только к переменным типа `System.Data.DataTable`.

## 📋 Элементы

| Элемент | Что делает и когда нужен |
| :--- | :--- |
| **Создать таблицу** | Создаёт пустую таблицу с нужными столбцами. Отправная точка, когда данные собираются «с нуля», а не читаются из файла. |
| **Добавить столбец** | Добавляет новый столбец в существующую таблицу. Нужен, чтобы дополнить данные на лету — например, добавить колонку с результатом расчёта. |
| **Добавить строку** | Добавляет новую строку с данными в существующую таблицу. |
| **Искать в таблице** | Находит значение или номер строки по условию. Нужен, чтобы быстро проверить наличие записи, не перебирая строки вручную. |
| **Сортировать таблицу** | Сортирует строки по значению столбца. Нужен для подготовки отчётов или выбора «топ-N» записей. |
| **Объединить таблицы** | Склеивает две таблицы в одну. Нужен, когда данные приходят из нескольких источников (например, два файла Excel), а обрабатывать их нужно вместе. |
| **Удалить колонку** | Убирает лишний столбец из таблицы. Нужен для очистки данных перед выгрузкой — например, убрать служебную колонку. |
| **Удалить строку** | Удаляет строку из таблицы по её индексу. |
| **Удалить повторяющиеся строки** | Убирает дубликаты строк. Нужен при объединении данных из нескольких источников, где записи могут повторяться. |
| **Очистить таблицу** | Удаляет все данные, но сохраняет структуру столбцов. Нужен, когда таблицу нужно переиспользовать в цикле, не создавая заново. |
