# Дата

| №  | Название активности | Краткое описание процесса |
|----|--------------------------------------|----------------------------------------------------|
| 1  | Дата к строке						| Пример преобразования даты из DateTime в String. В примере осуществлено преобразование текущей даты в строку в формате "yyyy.MM.dd HH:mm.ss". |
| 2  | Изменить дату                     	| Компонент позволяет изменить дату в формате DateTime. В примере осуществлен процесс изменения текущей даты в части года - текущий год минус 5 лет. |
| 3  | Разница дат				            | Компонент позволяет получить разницу двух дат в формате DateTime. В примере осуществлен процесс получающий разницу между текущим годом и прошлым годом. |
| 4  | Строка к дате			          	| Компонент позволяет преобразовать дату из формата String в DateTime. В примере осуществлен процесс конвертирующий дату 20.08.2020 14:12.57 из типа данных String в DateTime. |
| 5  | Текущая дата		  					| Компонент позволяет получить текущую дату и время из системных часов ОС в формате DateTime. |
| 6  | Часть даты             				| Компонент позволяет извлечь часть даты. В примере осуществлен процесс извлечения года из текущей даты. |
