# Архивирование

| №  | Название активности | Краткое описание процесса |
|----|--------------------------------------|----------------------------------------------------|
| 1  | Извлечь архив						| Пример процесса применения компонента "Извлечь архив". Компонент позволяет извлечь файлы из существующего архива. В примере осуществлено извлечение файлов из архива .\Дополнительные материалы\Архив\Входные данные\123.zip |
| 2  | Создать архив 	           			| Пример процесса применения компонента "Создать архив". Компонент позволяет создать новый архив из указанной папки с файлами. В примере осуществлено архивирование данных из папки .\Дополнительные материалы\Архив\Входные данные\Архивировать\ |
