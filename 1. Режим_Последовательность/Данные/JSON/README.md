# JSON

| №  | Название активности | Краткое описание процесса |
|----|--------------------------------------|----------------------------------------------------|
| 1  | JSON к объекту						| Пример процесса применения компонента "JSON к объекту". Компонент позволяет преобразовать JSON в объекты .NET для дальнейших манипуляций с этими объектами. В примере осуществлен процесс извлечения данных из JSON-ответа от сервера и преобразование их объекты. |
| 2  | Объект к JSON	           			| Пример процесса применения компонента "Объект к JSON". Компонент преобразует объект .NET в строку формата JSON. В примере осуществлен процесс преобразования из анонимного типа данных в строку JSON. |
