# Тестирование

Элементы для тестирования и отладки процессов: проверки условий, заглушки вместо реальных вызовов и работа с тестовыми данными.

## 📋 Элементы

| Элемент | Что делает и когда нужен |
| :--- | :--- |
| **Заглушка** | Временно заменяет реальную активность фиктивной, возвращающей заданное значение. Нужна при разработке и отладке — чтобы протестировать логику без реального взаимодействия с системой (без подключения к БД, почте, SAP и т.д.). |
| **Проверка выражения** | Проверяет, что логическое условие истинно, и фиксирует результат в логе. Нужна для автоматических проверок — убедиться, что обработанные данные соответствуют ожиданиям. |
| **Проверка выражения с оператором** | Сравнивает два значения с заданным оператором (равно, больше, содержит и т.д.) и фиксирует, прошла ли проверка. Нужна, когда важен не просто факт условия, а конкретное отношение двух величин. |
| **Проверка результатов с оператором** | Сравнивает фактический результат операции с ожидаемым. Нужна для тестирования по шаблону «ожидаю X — получил Y». |
| **Получить следующие локальные тестовые данные** | Берёт очередную строку из локального набора тестовых данных (Dictionary). Нужна, когда процесс нужно прогнать на нескольких наборах входных данных без ручного изменения переменных. |
| **Сохранить переменные** | Записывает значения переменных в файл. Нужна при отладке — чтобы сохранить состояние процесса в момент ошибки и проанализировать позже. |
