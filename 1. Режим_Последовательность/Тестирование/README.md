# Тестирование


| №  | Название активности | Краткое описание процесса |
|----|--------------------------------------|----------------------------------------------------|
| 1  | Заглушка								| Компонент предназначен для временной замены реальной активности на фиктивную, что позволяет изолировать части сценария при тестировании или отладке. |
| 2  | Проверка выражения					| Компонент предназначен для валидации логического выражения с автоматической фиксацией результата проверки в консоли студии. В случае положительного результата в консоли появится лог "Проверка выражения прошла успешно", иначе "Тест завершен неудачно". |
| 3  | Проверка выражения с оператором		| Компонент предназначен для сравнения двух значений с использованием операторов (равно, больше, меньше, содержит и др.) с генерацией отчёта о результате сравнения. |
| 4  | Проверка результатов с оператором	| Компонент предназначен для валидации фактического результата операции против ожидаемого значения с использованием заданного оператора сравнения и фиксацией отклонений. |
| 5  | Получить следующие локальные тестовые данные		| Компонент предназначен для извлечения очередной строки тестовых данных из источника типа данных Dictionary<string, object>. |
| 6  | Сохранить переменные					| Компонент предназначен для записи значений переменных в файл для последующего анализа, отладки или использования в других тестовых сценариях. |
