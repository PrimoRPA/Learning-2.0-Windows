# Рабочий стол


| №  | Название активности | Краткое описание процесса |
|----|--------------------------------------|----------------------------------------------------|
| 1  | Запустить приложение					| Компонент предназначен для запуска внешнего приложения по пути к исполняемому файлу с возможностью передачи аргументов командной строки и указания рабочей директории. В примере осуществлен процесс запуска тестового приложения My CRM. |
| 2  | Присоединиться к приложению			| Компонент является контейнером и предназначен для подключения к уже запущенному экземпляру приложения по его имени процесса или заголовку окна для последующего управления через элементы интерфейса. В примере осуществлен процесс присоединения к тестовому приложению My CRM. |
| 3  | Активировать процесс					| Компонент предназначен для перевода окна указанного процесса в активное состояние и перемещения его на передний план рабочего стола. В примере осуществлен процесс перемещения на передний план тестового приложения My CRM. |
| 4  | Получить активное окно				| Компонент предназначен для определения и получения ссылки на окно, которое в данный момент находится в фокусе ввода операционной системы. |
| 5  | Развернуть окно						| Компонент предназначен для изменения состояния окна приложения на развёрнутое (максимизированное) с заполнением всего рабочего пространства экрана. В примере осуществлен процесс разворачивания тестового приложения My CRM. |
| 6  | Свернуть окно						| Компонент предназначен для сворачивания окна приложения в панель задач без завершения его работы. В примере осуществлен процесс сворачивания тестового приложения My CRM. |
| 7  | Восстановить окно					| Компонент предназначен для возврата окна приложения из свёрнутого или развёрнутого состояния в нормальный размер и позицию. В примере осуществлен процесс восстановления тестового приложения My CRM. |
| 8  | Завершить приложение					| Компонент предназначен для корректного завершения работы приложения через отправку сигнала закрытия окна. В примере осуществлен процесс закрытия тестового приложения My CRM. |
| 9  | Уничтожить процесс					| Компонент предназначен для принудительного завершения процесса операционной системы по его имени. В примере осуществлен процесс принудительного закрытия тестового приложения My CRM. |
| 10  | Список процессов					| Компонент предназначен для получения списка всех запущенных процессов в системе с информацией об их идентификаторах, путях и статусах. В свойствах элемента возможно указать, хотите ли вы получить все процессы или только процессы текущего пользователя. Список процессов будет сохранен в указанную переменную. |
| 11  | Снимок рабочего стола				| Компонент предназначен для захвата изображения всего экрана или указанной области с сохранением в переменную для последующего сохранения изображения с помощью элемента "Запись в файл". |
| 12  | Запись видео рабочего стола			| Компонент является контейнером и предназначен для записи видеопотока с экрана в течение времени выполнения элементов внутри этого контейнера с сохранением в видеофайл. |
| 13  | Разрешение							| Компонент предназначен для получения текущего разрешения экрана или изменения разрешения дисплея для адаптации сценария под различные конфигурации рабочего места. |
| 14  | Раскладка							| Компонент предназначен для переключения раскладки клавиатуры (языка ввода) в операционной системе или получения текущей активной раскладки. |
| 15  | Блокировка ввода					| Компонент является контейнером и предназначен для временной блокировки пользовательского ввода с клавиатуры и мыши во избежание случайного вмешательства в процесс выполнения сценария. Блокировка будет работать в течение времени выполнения элементов внутри этого контейнера. |
| 16  | Эмуляция ввода текста				| Компонент предназначен для отправки текстовых данных напрямую в активное окно приложения через системные события клавиатуры. В примере осуществлен процесс эмуляции вводе в тестовое приложение My CRM. |
| 17  | Эмуляция спецкнопки					| Компонент предназначен для имитации нажатия системных и функциональных клавиш (Ctrl, Alt, Tab, F1-F12 и др.) с возможностью комбинаций и удержания клавиш. |
| 18  | Прочитать консоль					| Компонент предназначен для извлечения текстового вывода из окна консольного приложения (cmd.exe, PowerShell) для анализа результатов выполнения команд или скриптов. Более подробное описание использования находится по ссылке: https://docs.primo-rpa.ru/primo-rpa/g_elements/el_basic/els_desktop/el_desktop_readconsole. |
| 19  | Чтение таблицы						| Компонент предназначен для извлечения табличных данных из приложения или браузера и дельнейшей записи данных в переменную типа данных System.Data.DataTable. |
