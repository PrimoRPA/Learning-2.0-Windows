# Файловая система


| №  | Название активности | Краткое описание процесса |
|----|--------------------------------------|----------------------------------------------------|
| 1  | Создать файл							| Компонент предназначен для создания нового пустого текстового файла по указанному пути.  |
| 2  | Создать папку						| Компонент предназначен для создания новой директории (папки) в файловой системе с возможностью создания вложенных директорий. |
| 3  | Чтение файла							| Компонент предназначен для извлечения содержимого файла с сохранением данных в переменную в виде текста или массива байт с изменением настроек кодировки. |
| 4  | Запись в файл						| Компонент предназначен для сохранения данных в файл с перезаписью существующего содержимого. |
| 5  | Добавить строку						| Компонент предназначен для записи текстовой строки в конец файла с автоматическим добавлением символа перевода строки, что удобно для ведения логов или текстовых списков. |
| 6  | Копировать файл						| Компонент предназначен для создания копии файла по новому пути с сохранением содержимого файла с возможностью перезаписи существующего файла или переименования. |
| 7  | Переместить файл						| Компонент предназначен для изменения расположения файла в файловой системе с возможностью переименования. |
| 8  | Удалить файл или папку				| Компонент предназначен для безвозвратного удаления файла или директории с возможностью рекурсивного удаления содержимого папки. |
| 9  | Существует файл или папка			| Компонент предназначен для проверки наличия файла или директории по указанному пути с возвратом логического значения (истина/ложь) для использования в условных конструкциях. |
| 10  | Информация о файле 					| Компонент предназначен для получения метаданных файла: размер, дата создания и изменения, путь и расширение. |
| 11  | Поиск файлов 						| Компонент предназначен для рекурсивного поиска файлов в указанной директории по маске имени, расширению или другим критериям с возвратом списка найденных файлов. |
