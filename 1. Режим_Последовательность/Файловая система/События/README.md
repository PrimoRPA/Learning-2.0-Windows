# Файловая система / События

Элементы для реакции на изменения в файловой системе.

## 📋 Элементы

| Элемент | Что делает и когда нужен |
| :--- | :--- |
| **Событие изменения файла** | Ожидает появления, изменения или удаления файла/папки по указанному пути и запускает следующую часть процесса, как только это произошло. Нужен, когда процесс должен стартовать по факту появления файла — например, входящие выгрузки кладут в папку, а робот подхватывает их и обрабатывает сразу, не проверяя папку каждые N минут. |
