# Криптография

Элементы для безопасного хранения и использования паролей и учётных данных.

> Учётные данные рекомендуется хранить в зашифрованном виде — через Credential Manager или Оркестратор, но не в открытом тексте в коде процесса.

## 📋 Элементы

| Элемент | Что делает и когда нужен |
| :--- | :--- |
| **Записать в Credentials** | Сохраняет логин и пароль в системное хранилище Credential Manager. Нужен при первоначальной настройке — чтобы один раз записать учётные данные, а потом только читать их. |
| **Прочитать Credentials** | Считывает логин и пароль из Credential Manager в защищённую переменную. Основной способ безопасно получить учётные данные в процессе, не держа пароль в открытом виде. |
| **Удалить Credentials** | Удаляет запись из Credential Manager. Нужен при ротации паролей или очистке после завершения проекта. |
| **SecureString к строке** | Преобразует защищённую строку (SecureString) в обычный текст. Нужен, когда приложение требует строку, а учётные данные хранятся в формате SecureString — например, после чтения из Оркестратора. |
