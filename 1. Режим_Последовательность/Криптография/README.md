# Криптография

##Учетные данные пользователей рекомендованно передавать в формате защищенной строки. Учетные данные в формате SecureString вы можете получить из Primo RPA Orchestrator или из Credential Manager.

| №  | Название активности | Краткое описание процесса |
|----|--------------------------------------|----------------------------------------------------|
| 1  | SecureString к строке				| Активность используется для преобразования данных типа SecureString в String. В примере осуществлен процесс создания переменной типа данных System.Security.SecureString, далее, с помощью активности "SecureString к строке" происходит преобразованиие в тип данных String. |
| 2  | Записать в Credentials              	| Активность используется для записи учетных данных в Credential Manager для последующего использования. |
| 3  | Прочитать Credentials               	| Активность используется для чтения учетных данных из Credential Manager для последующего использования. Защищенные данные записываются в переменную с типом данных "LTools.Common.Model.UserPass". |
| 4  | Удалить из Credentials              	| Активность используется для удаления учетных данных из Credential Manager по его ключу. |
