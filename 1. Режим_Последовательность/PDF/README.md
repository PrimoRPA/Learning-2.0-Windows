# PDF

Элементы для работы с PDF-документами: чтение текста, объединение, разбиение, извлечение изображений и конвертация страниц.

## 📋 Элементы

| Элемент | Что делает и когда нужен |
| :--- | :--- |
| **Чтение текста** | Извлекает текстовое содержимое PDF в строку. Нужен, когда данные из PDF нужно прочитать и дальше обработать в процессе — без ручного копирования. |
| **Информация о документе** | Возвращает метаданные PDF: название, автора, дату создания и т.д. Нужен, когда по свойствам документа нужно принять решение — актуален ли он, кем создан. |
| **Кол-во страниц** | Возвращает количество страниц в документе. Нужен, например, чтобы проверить, не пустой ли документ, или чтобы запустить цикл по страницам. |
| **Извлечь страницы** | Вырезает выбранные страницы в отдельный PDF. Нужен, когда из большого пакетного документа нужно сохранить только нужные листы. |
| **Объединение документов** | Склеивает несколько PDF в один. Нужен, когда отдельные части документа (разделы, приложения) нужно собрать в единый файл для отправки. |
| **Добавление водяного знака** | Накладывает изображение или текст поверх страниц. Нужен для маркировки документов — «Копия», «Конфиденциально», штамп с датой. |
| **Получение изображений** | Извлекает все изображения из документа в папку. Нужен, когда в PDF встроены фотографии, подписи или схемы, которые нужно сохранить отдельно. |
| **Преобразовать в изображение** | Конвертирует страницы PDF в файлы-картинки (PNG/JPG). Нужен, когда документ нужно передать системе, которая работает только с изображениями, — например, OCR. |
