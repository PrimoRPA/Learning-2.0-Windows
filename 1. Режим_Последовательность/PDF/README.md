# PDF

| №  | Название активности | Краткое описание процесса |
|----|--------------------------------------|----------------------------------------------------|
| 1  | Добавление водяного знака            | Пример процесса добавления водяного знака в существующий документ PDF. |
| 2  | Извлечь страницы                     | Пример процесса извлечения определенных страниц в отдельный документ из существующего многостраничного PDF документа. |
| 3  | Информация о документе               | Пример процесса извлечения метаданных из существующего PDF документа и вывод результата в окно сообщения. |
| 4  | Кол-во страниц          				| Пример процесса извлечения количества страниц из существующего PDF документа и вывод результата в окно сообщения. |
| 5  | Объединение документов  				| Пример процесса объединения двух существующих PDF документов. Результатом является появление нового PDF документа, содержащий данные из двух указанных документов. |
| 6  | Получить изображение                 | Пример процесса получения всех изображений из сущесвующего PDF документа со всех страниц. Далее, с помощью цикла, изображения сохраняются в указанную директорию с помощью компонента "Запись в файл" (описание данного компонента можно найти в разделе "Файловая система") |
| 7  | Преобразовать в изображение          | Пример процесса конвертирования всех страниц существующего PDF документа в изображения. Далее, с помощью цикла, изображения сохраняются в указанную директорию с помощью компонента "Запись в файл" (описание данного компонента можно найти в разделе "Файловая система") |
| 8  | Чтение текста                 		| Пример процесса извлечения текстового слоя PDF документа с определённой страницы. Текст из документа выводится в консоль Primo Studio. |
