# ActiveMQ

Элементы для обмена сообщениями через брокер **Apache ActiveMQ**.

## Что такое ActiveMQ

ActiveMQ — корпоративный брокер сообщений с поддержкой очередей (queue) и топиков (topic). Очередь гарантирует, что каждое сообщение получит ровно один потребитель. Топик рассылает сообщение всем подписчикам. Часто используется в корпоративных интеграциях как шина между разными системами.

> Перед использованием нужно настроить подключение к серверу ActiveMQ: адрес, порт (по умолчанию 61616), имя пользователя и пароль.

## 📋 Элементы

| Элемент | Что делает и когда нужен |
| :--- | :--- |
| **Отправить сообщение** | Публикует сообщение в очередь или топик ActiveMQ. Нужен, когда Primo RPA должен уведомить другую систему о событии — например, сообщить ERP, что документ обработан, или поставить задание в очередь для другого сервиса. |
| **Получить сообщения** | Считывает доступные сообщения из очереди или топика в массив. Нужен, когда Primo RPA должен реагировать на события из других систем — например, получать уведомления о новых заявках, которые другой сервис публикует в ActiveMQ. |
