# ActiveMQ

##ActiveMQ - это брокер сообщений, обеспечивающий обмен сообщениями между приложениями.

| №  | Название активности | Краткое описание процесса |
|----|--------------------------------------|----------------------------------------------------|
| 1  | Отправить сообщение					| Компонент, отправляющий сообщение в очередь сервера ActiveMQ. Данный компонент в Primo можно применить для оркестрации процессов или интеграции с другими системами. |
| 2  | Получить сообщения            		| Компонент позволяющий получить массив сообщений от брокера сообщений ActiveMQ. |
