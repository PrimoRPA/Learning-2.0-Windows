# Буфер обмена

Элементы для работы с буфером обмена (clipboard) компьютера.

## 📋 Элементы

| Элемент | Что делает и когда нужен |
| :--- | :--- |
| **Отправить в буфер обмена** | Помещает данные в буфер обмена, как будто пользователь нажал Ctrl+C. Нужен, когда данные нужно вставить в приложение, у которого нет других способов ввода, кроме Ctrl+V. |
| **Получить из буфера обмена** | Считывает текущее содержимое буфера обмена в переменную. Нужен, когда приложение не отдаёт данные никак иначе, кроме как через Ctrl+C — например, некоторые ERP-системы. |
