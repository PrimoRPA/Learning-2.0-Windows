# MS Exchange

Элементы для работы с корпоративной почтой через Microsoft Exchange Server или Office 365.

> Все элементы этого раздела должны находиться внутри контейнера **«Сервер MS Exchange»**. Потребуются адрес сервера и учётные данные с доступом к Exchange.

## 📋 Элементы

| Элемент | Что делает и когда нужен |
| :--- | :--- |
| **Сервер MS Exchange** | Устанавливает подключение к серверу Exchange. Контейнер — без него остальные элементы раздела не работают. |
| **Чтение почты (MS Exchange)** | Считывает письма из указанной папки с возможностью фильтрации по теме, отправителю, дате. Полнее, чем IMAP — возвращает флаги, категории и другие Exchange-атрибуты. |
| **Отправить сообщение (MS Exchange)** | Отправляет письмо через Exchange. Нужен, если SMTP-порт закрыт или компания требует отправки только через Exchange. |
| **Переместить в папку (MS Exchange)** | Перемещает письмо между папками ящика Exchange. |
| **Пометить сообщение (MS Exchange)** | Ставит флаг «прочитано», «важное» или другой статус. Нужен, чтобы отметить обработанное письмо прямо в ящике — для контроля и во избежание повторной обработки. |
| **Сохранить вложения (MS Exchange)** | Сохраняет вложения письма на диск. Нужен, когда из письма нужно достать файлы для дальнейшей обработки. |
| **Сохранить сообщение (MS Exchange)** | Сохраняет письмо целиком в файл на диске. |
| **Удалить сообщения (MS Exchange)** | Удаляет письма из ящика Exchange. |
