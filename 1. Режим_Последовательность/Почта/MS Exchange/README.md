# MS Exchange

##Все компоненты связанные с MS Exchange должны находиться внутри контейнера "Сервер MS Exchange". Для успешного использования компонентов раздела необходимо указать учетные данные и адрес сервера Exchange.


| №  | Название активности | Краткое описание процесса |
|----|--------------------------------------|----------------------------------------------------|
| 1  | Сервер MS Exchange					| Данный элемент является контейнером для других элементов раздела MS Exchange. Элемент производит подключение к серверу Microsoft Exchange и позволяет роботу взаимодействовать с ним для выполнения операций с электронной почтой. В примере осуществлен процесс подключения к серверу MS Exchange с заполненными свойствами этого контейнера. |
| 2  | Отправить сообщение (MS Exchange)	| Элемент позволяет отправлять электронные письма через Exchange-сервер с вложениями в письме, если это требуется. В примере осуществлен процесс подключения к серверу MS Exchange и отправки письма с вложением. |
| 3  | Переместить в папку (MS Exchange)	| Элемент позволяет перемещать сообщения между папками MS Exchange. В примере осуществлен процесс перемещения сообщений из папки "Входящие" в папку "Удалённые".|
| 4  | Пометить сообщение (MS Exchange)		| Элемент позволяет проставлять пометки на сообщениях электронной почты в MS Exchange, такие как Прочитано, Не прочитано, Важность - высокая, низкая, нормальная. В примере осуществлен процесс чтения трёх первых сообщений и проставление пометки "Прочитано". |
| 5  | Сохранить вложения (MS Exchange)		| Элемент позволяет сохранить вложение из письма. В примере осуществлен процесс чтения первых двух писем, далее выполнено применение элемента "Сохранить вложения". |
| 6  | Сохранить сообщение (MS Exchange)	| Элемент предназначен для сохранения электронных писем, их заголовков, текста и вложений. В примере осуществлен процесс чтения первых трёх писем и их сохрание в локальную папку. |
| 7  | Удалить сообщения (MS Exchange)		| Элемент позволяет удалить сообщения электронной почты из MS Exchange. В примере осуществлен процесс чтения писем, далее эти письма будут удалены с помощью данной активности. |
| 8  | Чтение почты (MS Exchange)			| Элемент считывает сообщения для проведения дальнейших манипуляций с помощью других элементов. Число считываемых сообщений, сортировка, из какой папки сообщения можно задать в свойствах элемента. |
