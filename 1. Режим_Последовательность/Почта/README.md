# Почта

Элементы для отправки и получения электронной почты через стандартные почтовые протоколы (SMTP, IMAP, POP3) и Microsoft Exchange.

## 📋 Элементы

| Элемент | Что делает и когда нужен |
| :--- | :--- |
| **Отправить письмо (SMTP)** | Отправляет письмо через SMTP-сервер. Универсальный вариант — работает с любым почтовым сервером (Mail.ru, Яндекс, корпоративный). |
| **Получить письма (IMAP)** | Загружает письма из ящика по протоколу IMAP с возможностью фильтрации. Предпочтительный способ чтения почты — письма остаются на сервере, можно работать с папками. |
| **Получить письма (POP3)** | Загружает письма через POP3. Используется, когда сервер поддерживает только POP3, но стоит учитывать: письма обычно удаляются с сервера после загрузки. |
| **Переместить в папку (IMAP)** | Перемещает обработанное письмо в другую папку ящика. Нужен для классификации входящих — например, после обработки переложить в «Обработано». |
| **Удалить письма (IMAP)** | Удаляет письма с почтового сервера. Нужен после обработки, если хранить письма в ящике не нужно. |
| **Сохранить сообщение** | Сохраняет письмо (заголовок, тело, вложения) на локальный диск. Нужен для архивирования или передачи письма другому процессу в виде файла. |
