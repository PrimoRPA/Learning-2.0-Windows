# Ассистент

Элемент для отображения визуальной подсказки прямо на экране — поверх интерфейса приложения или браузера.

## 📋 Элементы

| Элемент | Что делает и когда нужен |
| :--- | :--- |
| **Подсказка** | Показывает текстовое окно-подсказку в нужном месте экрана: рядом с конкретным элементом интерфейса, в браузере или по заданным координатам. Нужен в сценариях «человек + робот» — когда робот не выполняет действие сам, а объясняет пользователю, что и где нужно сделать. Например: указать поле для заполнения, пояснить шаг инструкции или предупредить перед ручным подтверждением. Текст подсказки можно дополнительно озвучить голосом. |
