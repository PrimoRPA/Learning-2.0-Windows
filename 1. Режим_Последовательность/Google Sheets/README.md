# Google Sheets

## Для использования активностей необходимо проделать шаги по инструкции https://docs.primo-rpa.ru/ru/g_elements/el_basic/gsheets.

| №  | Название активности | Краткое описание процесса |
|----|--------------------------------------|----------------------------------------------------|
| 1  | Документ Google Sheets               | Указание ID документа, подключение к документу по его ID и файлу идентификации клиента приложения Google. |
| 2  | Запись диапазона                     | Указание ID документа, создание переменной типа List<Object> с данными, подключение к документу по его ID и файлу идентификации клиента приложения Google, запись в файл Google Sheets. Компонент "Запись диапазона" должен быть вложен в компонент "Документ Google Sheets" |
| 3  | Чтение диапазона                     | Указание ID документа, подключение к документу по его ID и файлу идентификации клиента приложения Google, чтение определённого диапазона документа и запись данных в переменную dtWIthInfo. Компонент "Чтение диапазона" должен быть вложен в компонент "Документ Google Sheets" |
