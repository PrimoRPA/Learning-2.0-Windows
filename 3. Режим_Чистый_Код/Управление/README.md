# Управление


| №  | Название активности | Краткое описание процесса |
|----|--------------------------------------|----------------------------------------------------|
| 1  | If-Else								| Компонент предназначен для выполнения одной из двух веток действий в зависимости от результата логического условия (истина/ложь). |
| 2  | Switch								| Компонент предназначен для выбора одной из множества веток выполнения на основе значения переменной или выражения с поддержкой значений по умолчанию. |
| 3  | Цикл While							| Компонент предназначен для повторного выполнения блока активностей до тех пор, пока заданное условие остаётся истинным (проверка перед каждой итерацией). |
| 4  | Цикл Do-While						| Компонент предназначен для выполнения блока активностей с последующей проверкой условия, гарантируя как минимум одну итерацию цикла. |
| 5  | Цикл ForEach							| Компонент предназначен для перебора всех элементов в коллекции, массиве или списке с автоматической передачей текущего элемента в переменную на каждой итерации. |
| 6  | Цикл ForEach для DataTable			| Компонент предназначен для итерации по строкам таблицы данных (DataTable) с возможностью доступа к значениям ячеек по имени столбца или его индексу. |
| 7  | Повтор исключений					| Компонент вызывает повторное исключение из блока Catch в контейнере Try-Catch. |
| 8  | Try-Catch							| Компонент предназначен для перехвата и обработки исключений, возникающих при выполнении блока активностей, с возможностью выполнения альтернативных действий в случае ошибки. |
| 9  | Исключение							| Компонент предназначен для генерации пользовательского исключения с заданным сообщением и типом ошибки для управления потоком выполнения или сигнализации о проблемах. |
| 10  | Выход из цикла						| Компонент предназначен для досрочного прерывания выполнения цикла и перехода к следующей активности за его пределами. |
| 11  | Продолжить цикл						| Компонент предназначен для немедленного перехода к следующей итерации цикла без выполнения оставшихся активностей в текущей итерации. |
| 12  | Ожидание							| Компонент предназначен для приостановки выполнения сценария на заданный промежуток времени в миллисекундах. |
| 13  | Присвоение							| Компонент предназначен для присвоения значения переменной. |
| 14  | Ссылка на процесс					| Компонент предназначен для вызова другого процесса или сценария из текущего проекта с передачей параметров и получением возвращаемых значений. |
| 15  | Закомментировать					| Компонент предназначен для временного отключения блока активностей без их удаления, что позволяет сохранить логику для отладки или будущего использования. |
