# Управление

Базовые элементы управления потоком выполнения: условия, циклы, обработка ошибок, вызов подпроцессов. Они есть в каждом процессе — это «каркас» любой логики. 

## 📋 Элементы

| Элемент | Что делает и когда нужен |
| :--- | :--- |
| **Присвоение** | Присваивает значение переменной. Самый простой и часто используемый элемент — для вычислений, счётчиков, хранения промежуточных результатов. |
| **If-Else** | Выполняет одну из двух веток в зависимости от условия (если/иначе). Основной элемент ветвления. |
| **Switch** | Выбирает одну из нескольких веток по значению переменной. Нужен вместо вложенных If-Else, когда вариантов много — код читается намного чище. |
| **Цикл While** | Повторяет блок, пока условие истинно (проверка перед каждой итерацией). Нужен, когда количество итераций неизвестно заранее — например, «пока есть необработанные записи». |
| **Цикл Do-While** | Как While, но проверка условия — после итерации. Гарантирует хотя бы одно выполнение. Нужен, когда блок должен выполниться как минимум один раз до проверки условия. |
| **Цикл ForEach** | Перебирает все элементы коллекции (List, Array). Нужен для обработки каждого элемента списка. |
| **Цикл ForEach для DataTable** | Перебирает строки таблицы DataTable. Нужен для построчной обработки данных из Excel или базы данных. |
| **Повтор исключения** | Аналог «Повтор попыток» с более гибкой настройкой обрабатываемых ошибок. |
| **Try-Catch** | Перехватывает ошибки внутри блока и позволяет обработать их — залогировать, продолжить, уведомить. Основной инструмент надёжной обработки исключений. |
| **Исключение** | Вручную выбрасывает ошибку. Нужен, когда бизнес-условие нарушено и дальнейшая работа невозможна — например, входные данные пустые или некорректные. |
| **Выход из цикла** | Прерывает выполнение текущего цикла (аналог `break`). Нужен, когда нужный результат найден и перебирать дальше нет смысла. |
| **Продолжить цикл** | Переходит к следующей итерации, пропуская остаток текущей (аналог `continue`). Нужен, когда текущий элемент нужно пропустить по условию. |
| **Закомментировать** | Отключает вложенные элементы от выполнения, не удаляя их. Нужен при отладке — временно выключить часть логики, чтобы изолировать проблему. |
| **Ожидание** | Приостанавливает процесс на заданное время. Нужен, когда следующий шаг нельзя делать сразу — например, дать приложению время загрузиться. Лучше использовать «Ожидание элемента» там, где оно есть. |
| **Ссылка на процесс** | Вызывает другой процесс (подпроцесс) как вложенный шаг. Нужен для разбиения большого процесса на переиспользуемые части. |
