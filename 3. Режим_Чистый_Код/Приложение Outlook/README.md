# Приложение Outlook.

##Для работы с любыми активностями группы "Приложение Outlook" необходимо использовать контейнер "Приложение Outlook". Так же необходимо чтобы MS Outlook был установлен на рабочей машине.

| №  | Название активности | Краткое описание процесса |
|----|--------------------------------------|----------------------------------------------------|
| 1  | Приложение Outlook					| Контейнер, обеспечивающий подключение к клиенту Microsoft Outlook и управление сеансом работы с почтовым ящиком. Все операции с почтой должны выполняться внутри данного контейнера. |
| 2  | Закрыть Outlook           			| Компонент предназначен для корректного завершения работы с приложением Outlook с возможностью сохранения несохранённых данных и отключения от почтового сервера. |
| 3  | Чтение почты         				| Компонент предназначен для получения списка сообщений из указанной папки (Входящие, Отправленные и др.) с возможностью фильтрации по атрибутам письма. В примере осуществлен процесс чтения почты из папки "Входящие" с темой писем содержащих "Обновление условий использования". |
| 4  | Отправить сообщение           		| Компонент предназначен для создания и отправки нового электронного письма с указанием получателей, темы, тела сообщения и вложенных файлов. В примере осуществлен процесс отправки письма получателю "test@primo-rpa.ru" и темой "Обучение PrimoRPA". |
| 5  | Переместить в папку       			| Компонент предназначен для переноса одного или нескольких сообщений из текущей папки в целевую папку (например, из "Входящих" в "Архив").  В примере осуществлен процесс перемещения списка сообщений из папки "Входящие" в папку "Архив". |
| 6  | Пометить сообщения       			| Компонент предназначен для установки категорий, таких как "Прочитано", "Не прочитано", важность "Высокая", "Низкая" и "Нормальная". В примере осуществлен процесс пометки списка сообщений с категорией "Важность - Высокая". |
| 7  | Сохранить вложение      				| Компонент предназначен для извлечения и сохранения файлов, прикреплённых к электронному письму, в указанную локальную директорию с сохранением исходного имени файла. В примере осуществлен процесс сохранения вложения из первого письма на локальный диск. |
| 8  | Сохранить сообщение       			| Компонент предназначен для экспорта полного содержимого письма (включая заголовки, тело и вложения) в файл различных форматов для архивации или дальнейшей обработки. В примере осуществлен процесс сохранения первого сообщения. |
| 9  | Читать адресную книгу      			| Компонент предназначен для получения контактов из глобальной адресной книги или локальной адресной книги Outlook с возможностью фильтрации по e-mail, имени, фамилии. В примере осуществлен процесс чтения адресной книги с фильтрацией по имени "Александр". Список адресов сохраняется в переменную listContact типа данных List<LTools.Office.Model.OContact> |
| 10  | Синхронизировать папку       		| Компонент предназначен для принудительного обновления содержимого почтовой папки с сервером обмена данными, что обеспечивает актуальность списка сообщений перед их обработкой. В примере осуществлен процесс синхронизации папки "Входящие". |
