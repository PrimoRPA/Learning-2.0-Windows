# Диалоги

Элементы для взаимодействия с пользователем, ведения журнала и управления заметками в Studio.

## 📋 Элементы

| Элемент | Что делает и когда нужен |
| :--- | :--- |
| **Окно сообщения** | Показывает модальное окно с текстом и кнопкой подтверждения. Нужен, когда роботу нужно сообщить пользователю что-то важное и дождаться его реакции перед продолжением. |
| **Всплывающее сообщение** | Показывает всплывающее уведомление (Toast), которое исчезает само. Нужен, когда нужно информировать пользователя, не прерывая работу процесса. |
| **Диалог ввода** | Открывает окно с полем ввода или списком выбора для получения данных от пользователя. Нужен, когда часть данных нельзя получить автоматически — например, выбор периода отчёта или ввод кода подтверждения. |
| **Пользовательский ввод** | Более гибкая форма получения ввода — позволяет задать несколько полей. Нужен, когда нужно запросить несколько параметров сразу, не открывая несколько диалогов. |
| **Выбор файла** | Открывает стандартный диалог выбора файла или папки. Нужен, когда путь к файлу не известен заранее и его должен указать пользователь. |
| **Запись в журнал** | Записывает сообщение в консоль Studio при отладке и в пользовательский журнал при запуске. Основной инструмент для отслеживания хода выполнения и поиска ошибок. |
| **Добавить поля журнала** | Добавляет дополнительные поля к записям журнала (например, ID задачи, имя клиента). Нужен, чтобы логи содержали контекст и их было легко фильтровать в Оркестраторе. |
| **Удалить поля журнала** | Убирает ранее добавленные дополнительные поля из журнала. |
| **Звуковой сигнал** | Воспроизводит системный звуковой сигнал. Нужен для привлечения внимания пользователя — например, когда роботу нужна помощь человека. |
| **Комментарий** | Добавляет текстовый комментарий к процессу — только для разработчика, на выполнение не влияет. Нужен для документирования сложных мест прямо в коде процесса. |
| **To Do** | Создаёт заметку в списке задач Studio. Нужен, когда при разработке нужно пометить место, к которому ещё вернёшься — задача видна в отдельной вкладке и кликабельна. |
