# Приложение Word

Элементы для автоматизации работы с документами Microsoft Word: чтение и редактирование текста, работа с таблицами, изображениями и форматированием.

> **«Документ Word»** — контейнер. Все остальные элементы должны находиться внутри него. После редактирования всегда нужно применять «Сохранить документ».

## 📋 Элементы

| Элемент | Что делает и когда нужен |
| :--- | :--- |
| **Документ Word** | Открывает файл Word и начинает сессию работы с ним. Контейнер — без него ни один другой элемент раздела не работает. |
| **Чтение текста** | Считывает текстовое содержимое документа или его части. Нужен, когда из Word нужно извлечь данные для дальнейшей обработки. |
| **Ввод текста** | Вставляет текст в указанную позицию документа или закладку. Нужен для заполнения шаблонных документов — например, договоров или актов. |
| **Заменить текст** | Заменяет все вхождения заданной строки на другое значение по всему документу. Основной способ заполнять шаблоны с плейсхолдерами вида `{ФИО}`, `{Дата}`. |
| **Найти текст** | Проверяет, есть ли в документе нужный фрагмент, и возвращает его позицию. Нужен, чтобы убедиться, что данные в документе присутствуют, перед их изменением. |
| **Удалить текст** | Удаляет фрагмент текста из документа. |
| **Вставить таблицу** | Вставляет таблицу в документ с заданным количеством строк и столбцов. |
| **Добавить строку таблицы** | Добавляет строку в существующую таблицу документа. Нужен при заполнении таблиц с переменным количеством строк — например, спецификации или реестра. |
| **Записать в ячейку таблицы** | Записывает значение в конкретную ячейку таблицы. |
| **Прочитать таблицу** | Считывает данные таблицы из документа в DataTable. Нужен, когда данные хранятся в Word-таблице и их нужно передать дальше в процесс. |
| **Вставка изображения** | Вставляет изображение в документ. Нужен, например, чтобы добавить логотип, подпись или результат скриншота. |
| **Получение фигур** | Возвращает список графических объектов документа. Нужен, когда в документе есть фигуры, которые нужно найти или изменить. |
| **Цвет шрифта** | Меняет цвет текста. Нужен для визуального выделения данных в документе. |
| **Цвет фона шрифта** | Меняет цвет фона (выделения) текста. |
| **Копировать в буфер обмена** | Копирует выделенный фрагмент документа в буфер обмена. |
| **Запустить макрос** | Запускает VBA-макрос, записанный в документе. |
| **Запустить VBA** | Выполняет VBA-функцию напрямую. |
| **Сохранить документ** | Сохраняет изменения в файле. Обязательно ставить в конце работы с документом. |
| **Экспортировать документ** | Сохраняет документ в другом формате — например, в PDF. |
