# Приложение Word.

##Для работы с любыми активностями группы "Приложение Word" необходимо использовать контейнер "Документ Word". При изменении документа средствами этой группы активностей, в конце процесса редактирования всегда нужно применять компонент "Сохранить документ".

| №  | Название активности | Краткое описание процесса |
|----|--------------------------------------|----------------------------------------------------|
| 1  | Документ Word						| Контейнер, обеспечивающий подключение к приложению Microsoft Word и управление сеансом работы с документом. Все операции с документом должны выполняться внутри данного контейнера. |
| 2  | Чтение текста           				| Компонент предназначен для извлечения текстового содержимого из всего документа или указанного диапазона (например, абзаца, выделенной области). В примере осуществлен процесс чтения текста из файла Word с начала и до 52 символа. |
| 3  | Ввод текста         					| Компонент предназначен для вставки текста в текущую позицию курсора или в указанное место документа. В примере осуществлен процесс ввода тектса с закладки "BookmarkPrimo". |
| 4  | Заменить текст           			| Компонент предназначен для массовой замены всех вхождений заданной строки или шаблона на новое значение по всему документу. В примере осуществлен процесс замены текста "Robotic Process Automation" на текст "Robotic Process Automation (RPA)". |
| 5  | Удалить текст       					| Компонент предназначен для удаления текста из документа по диапазону. В примере осуществлен процесс удаления текста с 52 позиции до 500. |
| 6  | Найти текст       					| Компонент предназначен для вывода индекса позиции первого совпадения текста документа и входной строки, а так же лист индексов всех совпадений текста и входной строки. В случае, если указанный текст не найден в документе Word, то переменная типа Int32 будет иметь значение -1, а переменная List<String> не будет иметь элементов. В примере осуществлен процесс поиска текста "бизнес-процессов". |
| 7  | Копировать в буфер обмена      		| Компонент предназначен для программного копирования выделенного фрагмента текста или объекта в системный буфер обмена для последующей вставки в другие приложения. В примере осуществлен процесс копирования текста с 5 позиции до 95. |
| 8  | Цвет шрифта       					| Компонент предназначен для изменения цвета текста в указанном диапазоне документа. В примере осуществлен процесс изменения цвета шрифра на красный с 0 позиции по 52.  |
| 9  | Цвет фона шрифта      				| Компонент предназначен для установки цвета заливки фона текста в заданном диапазоне символов или абзацев. В примере осуществлен процесс изменения цвета фона шрифта с 0 позиции по 52 на красный цвет. |
| 10  | Вставить таблицу       				| Компонент предназначен для создания новой таблицы. В примере осуществлен процесс двух видов: В первом варианте создается переменнтая dtTable типа данных System.Data.DataTable и заполняется построчно с помощью компонента "Добавить строку". Во втором варианте создается переменная listString типа данных List<List<string>>. |
| 11  | Добавить строку таблицы       		| Компонент предназначен для вставки новой пустой строки в существующую таблицу документа в указанную позицию по индексу. В примере осуществлен процесс добавления строки с помощью переменной dataRow типа данных System.Data.DataRow и с помощью переменной listString типа данных List<String>. |
| 12  | Записать в ячейку таблицы       	| Компонент предназначен для ввода текста или данных в конкретную ячейку таблицы по координатам (номер строки и столбца). В примере осуществлен процесс записи слова "Директор" в первую строку второй колонки. |
| 13  | Прочитать таблицу       			| Компонент предназначен для извлечения содержимого всей таблицы из документа Word. В примере осуществлен процесс чтения таблицы из нулевой позиции и запись данных в переменные типа данных System.Data.DataTable и List<List<string>>. |
| 14  | Вставка изображения       			| Компонент предназначен для добавления изображения в документ Word в определенное закладкой место. В примере осуществлен процесс преобразования изображения в двоичные данные и их запись в переменную image и вставка этого изображения в документ по закладке "BookmarkPrimo". |
| 15  | Получение фигур       				| Компонент предназначен для извлечения списка графических объектов (фигур, автофигур, диаграмм) из документа с получением их свойств и содержимого с записью в переменную с типом данных List<LTools.Office.Model.Word.DocShape>. |
| 16  | Сохранить документ       			| Компонент предназначен для сохранения изменений в текущем документе Word без изменения имени файла или пути его расположения. |
| 17  | Экспортировать документ       		| Компонент предназначен для сохранения документа в формат PDF. |
| 18  | Запустить макрос       				| Компонент предназначен для выполнения макроса, сохранённого в текущем документе Word. В примере осуществлен процесс запуска макроса с наименованием "ChangeColorVBA". |
| 19  | Запустить VBA       				| Компонент предназначен для выполнения кода на языке VBA непосредственно в контексте открытого документа Word для реализации сложной логики обработки. Скрипт должен находиться в отдельном файле. В примере осуществлен процесс запуска VBA скрипта меняющего стиль шрифта. |
