# HTML

| №  | Название активности | Краткое описание процесса |
|----|--------------------------------------|----------------------------------------------------|
| 1  | HTML к DataTable						| Пример процесса применения компонента "HTML к объекту". Данный компонент позволяет преобразовывать HTML-код в коллекцию таблиц. В примере создаётся HTML-таблица, далее идет преобразование HTML-таблицы в коллекцию таблиц с типом данных System.Data.DataTable. |
| 2  | HTML к объекту           			| Пример процесса применения компонента "HTML к объекту". Компонент, осуществляющий преобразование HTML в объект и поиск в этом объекте. В примере считывается HTML-код страницы, далее код преобразовывается в объект и результат выводится в консоль студии. |
