# XML

Элементы для работы с XML — форматом, который до сих пор используют многие интеграции: обмены с 1С, госреестрами и старыми корпоративными системами.

## 📋 Элементы

| Элемент | Что делает и когда нужен |
| :--- | :--- |
| **XML к объекту** | Разбирает XML-документ в объект для удобной работы с его содержимым. Нужен при получении данных из систем, которые отдают XML вместо JSON. |
| **Объект к XML** | Превращает объект или переменную в XML-документ. Нужен, когда систему-получателя устраивает только XML-формат. |
| **Запрос XPath** | Ищет и извлекает конкретные узлы или значения из XML по XPath-выражению — без необходимости перебирать весь документ вручную. |
