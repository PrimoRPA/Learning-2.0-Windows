# JSON

Элементы для преобразования между JSON и объектами .NET — нужны при работе с API и любыми системами, которые обмениваются данными в формате JSON.

## 📋 Элементы

| Элемент | Что делает и когда нужен |
| :--- | :--- |
| **JSON к объекту** | Превращает JSON-строку (например, ответ от API) в объект, с полями которого удобно работать напрямую — вместо того чтобы разбирать текст вручную. |
| **Объект к JSON** | Обратное преобразование — превращает объект или переменную в JSON-строку. Нужен, когда данные нужно отправить туда, что принимает только JSON: API, файл конфигурации, очередь сообщений. |
