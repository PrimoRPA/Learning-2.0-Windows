# Строки

Элементы для обработки текстовых строк: поиск, замена, разбор, проверка формата.

## 📋 Элементы

| Элемент | Что делает и когда нужен |
| :--- | :--- |
| **Длина строки** | Возвращает количество символов в строке. Нужен для проверок вида «ИНН должен состоять из 10 или 12 цифр». |
| **Поиск подстроки** | Находит, есть ли в строке нужный фрагмент, и на какой позиции. Нужен для быстрой проверки «содержит ли текст нужное слово» перед дальнейшей обработкой. |
| **Получить подстроку** | Вырезает часть строки по позициям символов. Нужен, когда нужный фрагмент текста всегда находится на одном и том же месте — например, часть кода документа. |
| **Заменить подстроку** | Заменяет один фрагмент текста на другой во всей строке. Нужен для очистки и нормализации данных — убрать лишние символы, привести к единому виду. |
| **Разделить строку** | Разбивает строку на части по разделителю (запятая, точка с запятой и т.д.). Нужен при разборе строк, где несколько значений склеены в одну — как строка CSV. |
| **Удалить пробелы** | Убирает лишние пробелы в начале и конце строки. Полезен перед сравнением строк или записью в базу — незаметные лишние пробелы часто ломают точное совпадение. |
| **Привести к строке** | Превращает значение любого типа (число, дата и т.д.) в текст. Нужен, когда данные разных типов нужно склеить или вывести вместе как текст. |
| **Регулярное выражение (IsMatch)** | Проверяет, соответствует ли строка заданному шаблону — да или нет. Нужен для валидации формата, например похож ли текст на номер ОГРН. |
| **Регулярное выражение (Matches)** | Находит в строке все фрагменты, подходящие под шаблон, и возвращает их списком. Нужен, когда из текста нужно вытащить сразу несколько совпадений — например, все ссылки на странице. |
