# Строки

| №  | Название активности | Краткое описание процесса |
|----|--------------------------------------|----------------------------------------------------|
| 1  | Длина строки							| Компонент позволяет вывести количество символов содержащейся в строке. В примере осуществлен процесс извлечения количества символов в ИНН для физических и юридических лиц. |
| 2  | Заменить подстроку                 	| Компонент позволяет заменить все вхождений подстроки в строке. В примере осуществлен процесс замены символа "тире" на пробел. |
| 3  | Поиск подстроки						| Компонент позволяет найти индекс первого вхождения искомого символа в исходной строке. В примере осуществлен процесс поиска символа "тире" и вывод индекса найденного символа. |
| 4  | Получить подстроку			    	| Компонент позволяет извлечь подстроку из исходной строки по индексам символов. В примере осуществлен процесс извлечения из строки "Выходные данные\\PrimoInfoWatermark" подстроку "Watermark". |
| 5  | Привести к строке			    	| Компонент позволяет преобразовывать данные из разных типов данных в String. В данном примере преобразуется текущая дата из DateTime в String.  |
| 6  | Разделить строку			    		| Компонент позволяет разделить строку на подстроки по определенному разделителю. В примере осуществлен процесс разделения строки "150000,2016-03-01,Chris Riley,trail.uou@example.com" на подстроки по символу ",". |
| 7  | Регулярное выражение (IsMatch)		| Компонент, применяющий регулярное выражение к заданной строке и возвращающий соответствие (True или False). В примере осуществлен процесс поиска из строки "Г.Москва, ОГРН: 1227700549780, Дата присвоения ОГРН: 06.09.2022, ИНН: 7708408569, КПП: 770901001" только часть с номером ОГРН. Если эта часть найдена - возвращается True, иначе False. |
| 8  | Регулярное выражение (Matches)		| Компонент осуществляющий поиск соответствий в строке с помощью регулярного выражения и возвращающий массив данных, если соответствия найдены. В примере осуществлен процесс извлечения URL из исходной строки. |
| 9  | Удалить пробелы			    		| Компонент позволяет удалить пробелы вначале и в конце исходной строки. В примере осуществлен процесс удаления пробелов из строки "    АВ400М 777RUS  ". В результате должна получиться строка "АВ400М 777RUS" |
