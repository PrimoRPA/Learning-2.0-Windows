# Коллекции

Элементы для работы с коллекциями данных: массивами и таблицами.

## 📋 Элементы

| Элемент | Что делает и когда нужен |
| :--- | :--- |
| **Таблицу в CSV** | Преобразует DataTable в строку CSV с заданным разделителем. Нужен, когда результат работы нужно сохранить в CSV-файл или передать системе, принимающей только CSV. |
