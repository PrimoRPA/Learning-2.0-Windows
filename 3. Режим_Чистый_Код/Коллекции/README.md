# Коллекции


| №  | Название активности | Краткое описание процесса |
|----|--------------------------------------|----------------------------------------------------|
| 1  | Таблицу в CSV               			| Активность используется для преобразования таблицы типа данных System.Data.DataTable в строковую переменную с добавлением определенного разделителя. В примере осуществлен процесс создания таблицы dtDataFromTable, добавления в неё данных и далее осуществлено преобразование в строковую переменную strTableInCsv с разделителем. |
