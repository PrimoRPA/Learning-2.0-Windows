# Страницы

Элементы для управления листами (страницами) книги Excel.

> Эти элементы должны находиться внутри контейнера **«Приложение Excel»**.

## 📋 Элементы

| Элемент | Что делает и когда нужен |
| :--- | :--- |
| **Список страниц** | Возвращает список названий всех листов книги. Нужен, чтобы перебрать листы в цикле или проверить, существует ли нужный лист. |
| **Добавить страницу** | Создаёт новый лист с указанным именем. Нужен, когда структура книги формируется динамически — например, по одному листу на каждый месяц или отдел. |
| **Переименовать страницу** | Меняет имя существующего листа. |
| **Копировать страницу** | Создаёт копию листа — с данными и форматированием. Нужен, когда есть шаблонный лист, который нужно размножить и заполнить данными. |
| **Удалить страницу** | Удаляет лист из книги. Нужен, например, чтобы убрать вспомогательный лист перед сохранением итогового файла. |
