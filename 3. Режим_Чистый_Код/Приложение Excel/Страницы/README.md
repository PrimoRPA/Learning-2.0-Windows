# Приложение Excel. Работа со страницами.

##Для работы с любыми активностями группы "Приложение Excel" необходимо использовать контейнер "Приложение Excel".

| №  | Название активности | Краткое описание процесса |
|----|--------------------------------------|----------------------------------------------------|
| 1  | Добавить страницу					| Компонент предназначен для создания нового листа с определенным именем в существующем файле Excel. В примере осуществлен процесс присоединения к файлу Excel, добавление нового листа с именем "Новая страница" и сохранение документа. |
| 2  | Копировать страницу           		| Компонент предназначен для копирования определенного листа в файле Excel. Лист будет скопирован полностью, со всеми данными и форматированием и может быть вставлен либо в этот же файл Excel, либо в другой файл. |
| 3  | Переименовать страницу         		| Компонент предназначен для изменения названия листа в существующем файле Excel. |
| 4  | Список страниц            			| Компонент предназначен для получения списка названий страниц в существующем файле Excel. В примере осуществлен процесс получения списка страниц из файла PrimoLearning.xlsx и данный список выводится в логи студии. |
| 5  | Удалить страницу       				| Компонент предназначен для удаления страницы из файла Excel по имени страницы или по индексу. В примере осуществлен процесс удаления страницы с названием "Копия персонала". |
