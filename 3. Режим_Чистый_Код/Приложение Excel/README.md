# Приложение Excel.

##Для работы с любыми активностями группы "Приложение Excel" необходимо использовать контейнер "Приложение Excel".

| №  | Название активности | Краткое описание процесса |
|----|--------------------------------------|----------------------------------------------------|
| 1  | Приложение Excel						| Контейнер, обеспечивающий подключение к приложению Microsoft Excel и управление сеансом работы с файлами. Все операции с Excel должны выполняться внутри данного контейнера. |
| 2  | Сохранить документ           		| Компонент предназначен для сохранения изменений в текущем файле Excel без изменения имени или пути расположения файла. |
| 3  | Сохранить как PDF         			| Компонент предназначен для экспорта содержимого листа или всего документа Excel в формат PDF с возможностью выбора диапазона и параметров вывода. |
| 4  | Установить пароль           			| Компонент предназначен для защиты файла Excel паролем на открытие или на изменение документа. |
| 5  | Чтение из ячейки       				| Компонент предназначен для извлечения значения из конкретной ячейки Excel по указанным координатам. В примере осуществлен процесс извлечения данных из ячейки "B3". |
| 6  | Ввод в ячейку       					| Компонент предназначен для записи текстовых или числовых данных в указанную ячейку Excel. В примере осуществлен процесс ввода в ячейку "F2" числа "10950,23" с заданным числовым форматом. |
| 7  | Чтение формулы из ячейки       		| Компонент предназначен для получения текста формулы, содержащейся в ячейке, без вычисления её результата. В примере осуществлен процесс чтения формулы из ячейки "E5". |
| 8  | Ввод формулы в ячейку       			| Компонент предназначен для вставки формулы в ячейку Excel с автоматическим её вычислением при обновлении листа. В примере осуществлен процесс ввода формулы "=СУММ(E2:E12)" в ячейку "E13". |
| 9  | Чтение колонки       				| Компонент предназначен для извлечения всех данных из указанного столбца файла Excel. В примере осуществлен процесс чтения данных из колонки "B2" и запись этих данных в переменную listExcelColumn типа данных List<Object>. |
| 10  | Выделение диапазона      			| Компонент предназначен для выделения диапазона ячеек на листе, что может использоваться перед операциями копирования или форматирования. В примере осуществлен процесс выделения диапазона "A1:B7". |
| 11  | Удаление диапазона       			| Компонент предназначен для очистки содержимого ячеек в указанном диапазоне с возможностью выбора типа удаления: только ячейки без удаления форматирования или очистка всего содержимого ячеек вместе с форматированием. В примере осуществлен процесс удаления диапазона "A2:B7" только содержимого ячеек. |
| 12  | Вставка строк       				| Компонент предназначен для добавления новых пустых строк в указанную позицию листа с автоматическим сдвигом существующих данных вниз. В примере осуществлен процесс вставки пяти строк начиная с третьей строки. |
| 13  | Удаление строк       				| Компонент предназначен для полного удаления строк из листа Excel с возможностью указания диапазона по номерам строк. В примере осуществлен процесс удаления одной строки с первой позиции. |
| 14  | Вставка колонок       				| Компонент предназначен для добавления новых пустых столбцов в указанную позицию листа с автоматическим сдвигом существующих данных вправо. В примере осуществлен процесс вставки двух колонок начиная со второй позиции. |
| 15  | Удаление колонок      				| Компонент предназначен для полного удаления столбцов из листа Excel с возможностью указания диапазона столбцов и их количества. В примере осуществлен процесс удаления первого столбца. |
| 16  | Поиск в диапазоне       			| Компонент предназначен для поиска значения в пределах заданного диапазона ячеек с возвратом координат найденной ячейки. В примере осуществлен процесс поиска в диапазоне "C1:C7" значения "менеджер". |
| 17  | Поиск на странице       			| Компонент предназначен для глобального поиска значения по всему листу Excel. В примере осуществлен процесс поиска значения "менеджер" на странице "Персонал". |
| 18  | Изменение ячейки       				| Компонент предназначен для настройки свойств ячейки: задание типа, цвета и толщины границы, изменение цвета ячеек. В примере осуществлен процесс изменения диапазона ячеек "A2:F12". |
| 19  | Изменение шрифта       				| Компонент предназначен для изменения параметров шрифта (начертание, размер, цвет, заливка) для указанного диапазона ячеек. В примере осуществлен процесс изменения шрифта в диапазоне "A2:E12". |
| 20  | Вставка диаграммы       			| Компонент предназначен для создания новой диаграммы (гистограмма, график, круговая и др.) на основе данных из указанного диапазона. В примере осуществлен процесс вставки диаграммы типа "Сгруппированная столбчатая диаграмма" из диапазона данных "B2:E12". |
| 21  | Пересчет формул      				| Компонент предназначен для принудительного пересчёта всех формул во всем файле или на активном листе.  |
| 22  | Обновление данных соединений       	| Компонент предназначен для обновления внешних данных, подключённых к книге Excel через соединения (например, из баз данных или веб-источников). |
