# Google Sheets

Элементы для работы с таблицами Google Sheets: подключение к документу, чтение и запись данных.

> Перед использованием нужно один раз настроить доступ к Google API — см. [инструкцию](https://docs.primo-rpa.ru/ru/g_elements/el_basic/gsheets).

## 📋 Элементы

| Элемент | Что делает и когда нужен |
| :--- | :--- |
| **Документ Google Sheets** | Подключается к нужной Google-таблице по её ID. Контейнер — с него начинается любая работа с Google Sheets, внутрь него кладутся элементы «Чтение диапазона» и «Запись диапазона». |
| **Чтение диапазона** | Считывает данные из указанного диапазона ячеек в таблицу (DataTable). Нужен, когда исходные данные для процесса хранятся в Google-таблице, а не в Excel или базе данных — например, общая таблица, с которой работает вся команда. |
| **Запись диапазона** | Записывает данные из процесса в указанный диапазон ячеек Google-таблицы. Нужен, чтобы результат работы робота сразу появился в общей таблице и был виден команде — без ручной выгрузки и вставки. |

## 💡 Когда стоит выбрать Google Sheets вместо Excel

Если таблица должна быть доступна нескольким людям одновременно и обновляться в реальном времени (например, общий реестр заявок или дашборд) — Google Sheets подходит лучше, чем локальный Excel-файл.
