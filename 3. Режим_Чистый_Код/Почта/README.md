# Почта


| №  | Название активности | Краткое описание процесса |
|----|--------------------------------------|----------------------------------------------------|
| 1  | Отправить письмо (SMTP)				| Компонент предназначен для отправки электронных писем через SMTP-сервер. |
| 2  | Переместить в папку (IMAP)           | Компонент предназначен для автоматизации процесса перемещения электронных писем между папками на почтовом сервере, использующем протокол IMAP.  |
| 3  | Получить письма (IMAP)         		| Компонент предназначен для получения электронных писем с почтового сервера, который использует протокол IMAP. |
| 5  | Сохранить сообщение       			| Компонент предназначен для сохранения электронных писем, их заголовков, текста и вложений на локальный диск компьютера. В примере осуществлен процесс считывания сообщений и их сохранение с помощью данного компонента. |
