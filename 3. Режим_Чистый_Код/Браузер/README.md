# Браузер

Элементы для автоматизации работы в браузере: открытие страниц, навигация, чтение данных со страницы, работа с вкладками.

> Компоненты **«Открыть браузер»** и **«Присоединиться к браузеру»** — контейнеры. Остальные элементы этого раздела должны находиться внутри одного из них. Для их работы нужно установить расширение для браузера — см. [гайд по установке](https://docs.primo-rpa.ru/primo-rpa/primo-rpa-studio/settings/plugin-install). Примеры используют Google Chrome.

## 📋 Элементы

| Элемент | Что делает и когда нужен |
| :--- | :--- |
| **Открыть браузер** | Запускает браузер и сразу переходит на нужный сайт. Контейнер — с него начинается любой веб-процесс, внутрь него кладутся остальные элементы этого раздела. |
| **Присоединиться к браузеру** | Подключается к уже открытому окну браузера вместо запуска нового. Нужен, когда сайт уже открыт (например, пользователем) и робот должен продолжить работу в этой же сессии, а не начинать заново. |
| **Открыть вкладку браузера** | Открывает новую вкладку в уже запущенном браузере. Нужен, когда приходится работать сразу с несколькими сайтами или страницами, не теряя текущую вкладку. |
| **Закрыть вкладку браузера** | Закрывает конкретную вкладку по названию или номеру, не трогая остальные. Полезен, когда открыто несколько вкладок и нужно закрыть только отработанную. |
| **Активировать вкладку браузера** | Делает нужную вкладку активной (переключает на неё фокус), если их открыто несколько. Нужен для переключения между вкладками по ходу процесса. |
| **Активная вкладка** | Возвращает информацию о вкладке, которая сейчас активна (адрес, заголовок и т.д.). Помогает роботу понять, где он находится, прежде чем выполнять следующий шаг. |
| **Перейти к странице** | Переходит по указанному адресу в текущей вкладке. Используется, когда нужно попасть на конкретную страницу напрямую, не кликая по ссылкам на сайте. |
| **Назад** | Аналог кнопки «Назад» в браузере — возвращает на предыдущую страницу истории. Быстрее и надёжнее, чем заново открывать страницу по ссылке. |
| **Вперёд** | Аналог кнопки «Вперёд» — возвращает на страницу, с которой до этого ушли назад. |
| **Обновить** | Перезагружает текущую страницу. Полезен, если данные на странице могли устареть — например, нужно перепроверить актуальный статус заказа. |
| **Закрыть браузер** | Завершает работу браузера и закрывает все его окна. Обычно ставится в конце процесса, чтобы не оставлять висящие окна. |
| **Получить атрибут** | Считывает значение HTML-атрибута элемента страницы (например, ссылку из атрибута `href`). Нужен, когда искомые данные хранятся не в видимом тексте, а в атрибуте — ссылки, id, data-атрибуты. |
| **Скачать изображение** | Скачивает изображение по прямой ссылке и сохраняет на диск. Нужен, когда с сайта требуется забрать конкретную картинку — скриншот, фото товара, документ в виде изображения. |
| **Выполнить JS** | Выполняет произвольный JavaScript-код прямо на открытой странице. Нужен, когда стандартных элементов недостаточно — например, чтобы получить данные, скрытые от обычного взаимодействия, или изменить страницу «на лету». |
