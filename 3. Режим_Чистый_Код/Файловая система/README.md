# Файловая система

Элементы для работы с файлами и папками: создание, чтение, запись, копирование, перемещение, поиск и удаление.

## 📋 Элементы

| Элемент | Что делает и когда нужен |
| :--- | :--- |
| **Существует файл или папка** | Проверяет, есть ли файл или папка по указанному пути. Нужен перед попыткой открыть или обработать файл — чтобы не получить ошибку на пустом месте. |
| **Информация о файле** | Возвращает свойства файла или папки: размер, дату создания и изменения, атрибуты. Нужен, когда решение зависит от свежести файла — например, брать только файлы моложе суток. |
| **Создать файл** | Создаёт новый пустой файл по указанному пути. Нужен, когда файл нужно создать заранее — например, для последующей записи в него. |
| **Создать папку** | Создаёт новую папку (включая вложенные). Нужен, когда перед сохранением файлов нужно убедиться, что папка существует. |
| **Чтение файла** | Считывает содержимое текстового файла в строку. Нужен, когда входные данные лежат в файле — конфигурация, список значений, текстовый отчёт. |
| **Запись в файл** | Записывает данные в файл, перезаписывая существующее содержимое. Нужен для сохранения результатов процесса в текстовый файл. |
| **Добавить строку** | Дописывает строку в конец файла, не затирая существующее содержимое. Нужен для ведения логов или пополняемых списков. |
| **Копировать файл** | Копирует файл в другое место. Нужен, когда оригинал нужно сохранить нетронутым — например, перед обработкой файла делать его резервную копию. |
| **Переместить файл** | Перемещает файл в другое место или переименовывает. Нужен для сортировки файлов по папкам после обработки. |
| **Удалить файл или папку** | Удаляет файл или папку. Нужен для очистки временных файлов после завершения работы. |
| **Поиск файлов** | Ищет файлы в указанной папке по маске (например, `*.xlsx`). Нужен, когда входные данные — папка с файлами, которые нужно перебрать. |
