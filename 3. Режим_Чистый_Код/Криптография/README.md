# Криптография

##Учетные данные пользователей рекомендованно передавать в формате защищенной строки. Учетные данные в формате SecureString вы можете получить из Primo RPA Orchestrator или из Credential Manager.

| №  | Название активности | Краткое описание процесса |
|----|--------------------------------------|----------------------------------------------------|
| 1  | Записать в Credentials              	| Активность используется для записи учетных данных в Credential Manager для последующего использования. |
| 2  | Прочитать Credentials               	| Активность используется для чтения учетных данных из Credential Manager для последующего использования. Защищенные данные записываются в переменную с типом данных "LTools.Common.Model.UserPass". |
| 3  | Удалить из Credentials              	| Активность используется для удаления учетных данных из Credential Manager по его ключу. |
